# YRK LAB logo

The flask, its colours and the "YRK LAB" letters are the same in every version; only what is shown changes.

| File | Shows | Use it for |
|---|---|---|
| `yrk-lab-mark.png` | the flask with the Y | program and browser-tab icons of YRK LAB itself |
| `yrk-lab.png` | flask + YRK LAB | website header or footer, menus, profile pictures |
| `yrk-lab-slogan.png` | flask + YRK LAB + "Your Reliable Kit" | the About window and start pages when there is room; covers, posters, introducing the company |

The rule: to be remembered, no slogan; to introduce who we are, with the slogan. At small sizes, where the slogan
cannot be read, use `yrk-lab.png`.

These are the full-size masters (transparent PNG). The program and the website use copies made from them:
`src/Yrk.PdfStudio.App/Assets/yrk-lab-slogan.png` (About) and `docs/release-repo/site-src/img/yrk-lab.png` (website footer).
The YRK PDF program icon (`build/icon-source.png`) is the product's own icon, not the YRK LAB logo.
