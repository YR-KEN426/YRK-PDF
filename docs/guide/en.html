Getting started

YRK PDF is free, with no ads and no account, and it never sends your files anywhere.

Opening files

  • Drag one or more PDFs from File Explorer onto the window.
  • Or press Ctrl+O, or the Open button. The arrow next to it lists recent files.
  • Select several files in the Open dialog; each one gets its own tab. If you select or drop more than 20 files, the app asks before opening them. If a file cannot be opened or you cancel its password prompt, the app skips it and continues with the next file.
  • Besides PDF, AutoCAD drawings (DWG, DXF) open too.
  • Reopening a file returns to the page you last read. The last 200 files are remembered on this computer only; clearing the recent files list clears this history too.

Start page

With no file open, or after the house button, the start page shows every tool, grouped by task. Click a card to start.

The main window

  • Top row: the File, View, Tools, Settings, Help menus (Alt and the first letter, such as Alt+F), then Open, Save, Print, page buttons, zoom and the search box.
  • Second row: the task tabs Comment · Edit · Fill & Sign · Pages · Measure · Redact, each with its own tools. Undo and Redo are at the far right.
  • Sidebar: page thumbnails, the comment list, signatures, drawing layers, bookmarks and reading marks. The three-line button at the top left shows or hides it.
Language: Settings → Language / ภาษา switches between English and Thai.

Scan to PDF

  1. Turn on your scanner and choose Scan to PDF from the start page. Select the scanner and a preset: Black-and-white document, Color document, Receipt, Two-sided ID card, Photo or Custom.
  2. Place the document on the glass or in the feeder, then press Scan. To add another page, press Space or Scan next page.
  3. Preview the pages. Select an area to scan, or use the handles on the image to crop it. Drag thumbnails to reorder pages; rotate or delete them as needed.
  4. Adjust brightness, contrast, sharpness and white background, or straighten the page. Choose whether the changes apply to this page, selected pages or all pages.
  5. Turn on OCR to make Thai and English text searchable in the PDF, then save as PDF or JPEG/PNG.
Tips: Pick a preset for the job; press Space to scan the next page; use the crop handles to fine-tune the edges; apply adjustments to this page, selected pages or all pages; turn on OCR to search the PDF text.
Document feeder: Tested with a flatbed scanner. The feeder and duplex scanning are an early version. If you run into a problem, please tell us the scanner model.

Before using OCR text, read OCR limitations and always check the result.

Reading and finding

Zooming and moving around

  • Zoom with the + and − buttons, or hold Ctrl and turn the mouse wheel. The zoom box has Fit page and Fit width.
  • Drag the page with the Hand tool (H), or hold Space and drag, or drag with the middle mouse button.
  • Go to a page by typing its number in the page box, or click its thumbnail in the sidebar.

Finding and copying

  • Press Ctrl+F, type, then Enter or F3 for the next result. Tick Aa to match upper and lower case.
  • Drag over text with the Select tool and press Ctrl+C to copy it.
  • Thai stored with its vowels or tone marks out of order is put right when you copy and search. Pages printed from Excel, whose stored text is jumbled, are copied and searched line by line as printed.
Scanned files: if search and copy find nothing, the pages are pictures. Use Convert scanned documents or Recognize text (OCR) first.

Reading marks 🔖 and bookmarks

Reading marks help you return to pages you want to read again. The Bookmarks tab shows the document outline supplied by the PDF's author.

  1. Go to a page, then press Reading marks on the toolbar or Ctrl+D. Enter a name of up to 40 characters, choose a colour, and press Add.
  2. Choose from six colours: red, orange, yellow, green, blue and purple. A coloured ribbon appears on the page and thumbnail, but is not included when printing or exporting.
  3. Right-click a thumbnail or the page and choose Add reading mark… or Edit reading mark… to manage the mark for that page, even when several thumbnails are selected.
  4. Open the Reading marks tab in the sidebar and click an entry to go to its page. Right-click an entry to rename it or change its colour. On a marked page, use the toolbar button or Ctrl+D to edit its name or colour, or press Remove.

Reading marks are stored only on this computer, not in the PDF, so they also work with signed or read-only files. You can save up to 100 marks per file for the 200 most recently opened files.

When you insert, move or delete pages, reading mark page numbers follow along and are saved with the document. Deleting a marked page also deletes its mark; Undo restores it with that step. If you discard unsaved page changes, marks return to match the original file. When you save as a new name, the marks go with the new file.

Keep your reading marks: they are also included in the app's backup file. Clearing recent files also clears reading marks and your last-read positions.

Highlights and comments

The Comment tab is for reviewing, marking up and leaving notes. Other PDF programs, Adobe Acrobat included, show them too.

  • Highlight, Underline, Strikeout: choose the tool and drag over text.
  • Note: click where it belongs, then type in the sidebar.
  • Pen, Rectangle, Ellipse, Arrow: drag on the page to draw.
  • Add text: click and type.
  • Colour and line width are on the same row.

Changing comments

  • With the Select tool, drag a comment to move it, or drag a corner to resize it.
  • Delete removes it; Ctrl+Z brings it back.
  • All comments are listed in the sidebar's Comments tab; click one to go there.

Editing text

Change words in the PDF itself, Thai included. The new words are real text that can be searched and copied.

  1. On the Edit tab, choose Edit text.
  2. Click the line to change. In a table only that cell is taken; the rest of the row stays where it is.
  3. Type, then press Enter or click somewhere else. The new text goes into the page at once.
  4. Not right? Ctrl+Z brings the old text back; Esc while typing cancels.

Fonts

The document's own font is used when it is installed on this PC. Otherwise a similar font is chosen and sized to look as tall. While typing, the bar at the top of the page changes the font, size, bold, italic and colour.

The file changes when you save: while you work the changes live in a temporary copy. Your file only changes on Ctrl+S.

Forms and signatures

Filling in a form

If the PDF has form fields, click one and type. Thai shows correctly, and the form can be filled on in Adobe Acrobat as usual.

Amounts in words: type an amount such as 10000 in a field (or in added text), right-click and choose Amount in Thai words for "หนึ่งหมื่นบาทถ้วน", or Amount in English words for "Ten Thousand Baht Only". Satang are written too (1234.50 is "หนึ่งพันสองร้อยสามสิบสี่บาทห้าสิบสตางค์").

Making your own form

  1. Fill & Sign tab → Create form: choose a field type, such as text, list or check box.
  2. Drag a box on the page, name the field and press Add field.
  3. Press Enter or click outside: the field can be filled straight away.
  4. Edit fields changes or deletes fields.

Amount in words

The Amount in words card in the home page's Accounting group, or Insert → Amount in words…, turns an amount into Thai and English words to copy or put on the page. In a form field or added text, a button appears under the box when you type an amount; right-clicking the number works too, also on added text already placed.

The Insert menu

The Insert menu in the top row (Alt+I) has everything that can be added to a file in one place: text, pictures, symbols, signatures, stamps, lines, arrows, shapes, the pen, notes, pages from another file, watermarks and page numbers.

  • Lines and arrows: drag on the page. Hold Shift for 45° steps, for an exactly level line.
  • Symbols: such as ✓ ✗ ☐ ☑ ● ★. Choose one and click where it should go. They resize like a picture and stay sharp at any size.
  • Choose the colour on the Comment tab.
  • Lines, arrows, shapes, pen strokes and notes are comments, so they can be moved or removed even after saving. Text, pictures, symbols and signatures become part of the page when saved.

Adding a picture

  • On the Fill & Sign tab, press Add picture, choose a file and click where it should go. Or copy a picture and press Ctrl+V, or drop a picture file on the window.
  • Drag the picture to move it, and its lower-right corner to resize it (the proportions stay). Use the Rotate handle above the box to rotate freely (hold Shift to snap to 15° steps), or press Rotate 90° clockwise (the ↻ 90° button), and use the ◐ button to set opacity from 10–100%. Delete or the × removes it; Ctrl+Z undoes.
  • Once the file is saved the picture is part of the page and can no longer be moved or resized, so place it before saving.

Signing

  1. Press Sign and create a signature: draw it with the mouse or a pen, type your name, or import a photo of it on white paper (the white is removed).
  2. Click the page to place it, then drag to move or resize it. Use the Rotate handle above the box to rotate freely (hold Shift to snap to 15° steps), or press Rotate 90° clockwise (the ↻ 90° button), and use the ◐ button to set opacity from 10–100%. Opacity cannot be adjusted for signatures imported from a PDF file.
  3. If you keep the signature for next time, it is stored encrypted on this PC.

Certified true copy

สำเนาถูกต้อง stamps "สำเนาถูกต้อง" (certified true copy) on a copy of an ID card or document, with your signature. Write what the copy is for, such as a job application, so it cannot be reused elsewhere, and add today's date if you like.

Rubber stamps

Rubber stamp has the stamps offices use every day: approved, received, paid, checked, original, copy, urgent, cancelled and confidential, with the date (Thai Buddhist year or English). Choose Thai, English, or both (the Thai word with the English one under it). Pick another date, change the words, colour and shape, or add small lines under the word, such as your company name or "by ......", then click Save to my stamps to use it again.

Click on the page to place the stamp; drag to move or resize it. Use the Rotate handle above the box to rotate freely (hold Shift to snap to 15° steps), or press Rotate 90° clockwise (the ↻ 90° button), and use the ◐ button to set opacity from 10–100%. Its words are saved as real text, so they can be searched and copied.

Edit saved pictures, stamps and signatures

Open the Edit tab and click an item placed by YRK and saved in the file to move, rotate, change its opacity or delete it (Ctrl+Z undoes the change). Pictures not placed by YRK can only be deleted. Saved items cannot yet be resized.

Items saved in version 1.2.0 can only be made fainter. Editing a digitally signed file may make the signature report that the document changed after signing.

To stamp a whole document, choose Same place on every page and click once: the stamp goes on every page (one Undo removes them all). Stamp many files at once… stamps a list of files or a folder, at a corner of the first or every page, and saves the results as new files.

Digital signatures (Digital ID)

A digital signature (PAdES) proves who signed and shows whether the document changed afterwards. Press Digital ID and choose an ID on a USB token, add a .pfx file from your certificate authority, or create your own. Choose whether the signature shows on the page and whether to add a trusted timestamp (needs internet). Signatures in a file are listed in the sidebar's Signatures tab.

Trusted certificates: In the Signatures panel, you can trust a signer using a self-signed certificate after checking its SHA-256 fingerprint with the owner through another channel. The status becomes Valid: you chose to trust this signer. This trust applies only in YRK on this computer; Acrobat may still show an unknown signer. Manage the list with the My trusted certificates button on the Fill & Sign tab: use Import .cer / .crt…, select a certificate and press Certificate to view it, or Delete to remove it. In your Digital ID details, open Certificate details… to see its fingerprint and use Export certificate (.cer) to export your public certificate.

  • Signature type: Approval for an ordinary signature, or Certify as the author to decide what may still happen afterwards (form filling and signing, comments as well, or no changes at all). Only the first signature of a document can certify it.
  • Before signing version: in the sidebar’s Signatures tab, press Save version before signing… to save a new file without changing the original. Before saving, the program explains which signatures and post-signing edits will be lost. This is unavailable for files rewritten in full during or after signing; copies already sent to others still have their signatures.
  • Signing an already signed file: the program warns before appending another signature. Existing signatures remain, and if there are unsaved changes, the earlier signature will show as changed after signing. Already signed files can only receive approval signatures; certification is not offered.
  • Long-term validation data: stores your certificates and their revocation lists in the file (PAdES B-LT), so the signature can be checked years later, even after the certificate expires. Best together with a trusted timestamp.

What the statuses mean:

  • Signed, but the document was changed after signing means the content changed after that signature. View signed version shows the version that was signed.
  • Adding more signatures one after another is normal and still shows valid.
  • Files co-signed in other programs may show “changed after signing” when that program changed other parts of the file while signing.
  • Timestamps are trusted only when the timestamp authority is trusted by Windows.
  • LTV files can be checked offline.

Backing up or deleting an ID: select an ID file in the digital signature window, enter its password, and press Back up this ID… or Delete this ID…. Documents already signed stay valid, but a deleted ID can sign nothing more; its file goes to the Recycle Bin. Certificates in Windows and USB tokens are managed with Windows or their issuer's tools.

Pages and files

  • Rotate, delete, insert, extract: select thumbnails in the sidebar (hold Ctrl for several), then use the Pages tab.
  • Move pages: drag a thumbnail to its new place.
  • Combine files: Tools → Combine files…; pick the files and put them in order.
  • Split: Tools → Split this PDF… saves chosen pages, or every few pages, as separate files, or splits at the bookmarks: one file per chapter, named after it, such as "01 - Introduction.pdf" (choose how many levels deep).
  • Images to PDF: Tools → Images to PDF… makes one PDF from photos and scans (JPG, PNG).
  • Watermark and page numbers: add a watermark, header, footer or page numbers from the Tools menu.

Cleaning up scans

Tools → Clean up scan (straighten, edges, blank pages)… (or the Clean up scans card on the home page) checks every page and shows what it found; tick what to fix:

  • Straighten tilted pages: turns a page scanned at an angle so its lines are level (up to about 6°).
  • Trim dark scanner edges: cuts off the black bands a scanner lid leaves around the page.
  • Delete blank pages: such as empty backs of sheets; specks and faint show-through from the other side still count as blank.

Ctrl+Z puts everything back, and the file only changes when you save.

Copy, cut and paste pages between files

  1. Open the source file and click a thumbnail to focus the thumbnail list. Select pages (hold Ctrl to select several), then press Ctrl+C or right-click and choose Copy pages.
  2. To move pages, press Ctrl+X or choose Cut pages. The pages are copied and removed from the source immediately, but the file on disk changes only when saved. You cannot cut every page and leave the file empty.
  3. Switch to the destination file, click the thumbnail after which to insert, then press Ctrl+V or right-click and choose Paste pages. With no thumbnail selected, pages are inserted after the current page. This works across tabs and app windows.
  4. You can also copy a PDF in File Explorer, then return and press Ctrl+V on the thumbnail list to insert all its pages.

Press Delete on the thumbnail list to remove selected pages. Ctrl+C/X/V act on pages only while the thumbnail list has focus; in text fields they continue to copy, cut and paste text.

Pages waiting to be pasted: the app warns when you close it or copy over cut pages that have not been pasted. Paste and save the destination before closing. To restore cut pages, press Ctrl+Z in the source file, because Undo is separate for each file. Undo in the destination removes only the pasted pages.

PDF permissions apply: the source must allow copying or extracting pages, and the destination must allow page changes. Signatures from the source do not travel with copied pages. If copied pages are no longer available, copy them again from the source.

Multi-line watermarks

Choose Tools → Watermark, header/footer and page numbers…. Type in Watermark text and press Enter for a new line, or choose Fit to page to wrap at spaces automatically, up to four lines.

Thai text: Thai text without spaces cannot be wrapped automatically. Press Enter to split it into lines yourself.

Watermarks appear over the content by default. Adjust Opacity and Angle; to put the watermark behind the content, choose Behind content.

Converting and compressing

PDF to Word

Editable text with tables and pictures in place

PDF to Excel

Tables as cells; amounts as numbers you can add up

PDF to PowerPoint

One slide per page, looking just like the PDF

PDF to images

Each page as a PNG or JPG picture

Start from the cards on the start page, or File → Export.

Compress PDF

Tools → Compress this PDF…, then choose:

  • Recommended, 150 dpi: good for email and most upload forms; text stays sharp.
  • Smallest file, 96 dpi: for strict size limits such as 1–2 MB.
  • High quality, 220 dpi: for printing.

A new copy is always saved; the original does not change. Photos and scans shrink a lot; files of plain text shrink little.

Recognize text (OCR)

Makes scans searchable and copyable, in Thai and English. It is on the Edit tab and in the Tools menu.

Convert scanned documents and review words

Use OCR to read text from scanned PDFs or images and reduce retyping. Choose searchable PDF, editable Word document or plain text as the output.

  1. Choose the Convert scanned documents card on the start page or Tools → Convert scanned documents…. Add PDF or image files, or a folder; you can also drop them into the window.
  2. Choose Thai and/or English, then select one or more Output formats: Searchable PDF, Word document or Text (.txt).
  3. Choose Review uncertain words before saving and press Convert. In the review page, words in orange boxes are words the app is unsure about. Click a word to compare it with the image, edit it and press Enter to confirm, or leave it blank to remove it.
  4. Save your review, then check the output files before using them. The results page has Open folder and Copy all text buttons.

Password-protected PDFs cannot be made searchable yet; save an unprotected copy first. For signed files, convert first and sign the output file afterwards.

OCR limitations

Always check the result: OCR reads text from images and can make mistakes, especially with blurry, skewed or small text and handwriting. Check names, numbers, dates and amounts every time. Words without orange boxes can also be wrong, so read all the text before using it.

Tip: scan at 300 dpi and keep the page straight. This advice applies when scanning to PDF, recognizing text from images and converting scanned documents.

PDF/A for archiving

The long-term archive format many offices ask for: Tools → Save as PDF/A (for archiving)…

Many files at once

Tools → Process many files… compresses, converts, watermarks or rubber-stamps a whole folder in one go.

Digital signatures: compressing or converting a digitally signed file makes the signature in the copy invalid. Do it before signing.

e-Tax Invoice

Makes a Thai tax invoice as PDF/A-3 with the Revenue Department's XML (ETDA standard ขมธอ. 3-2560) inside: the e-Tax Invoice card in the home page's Accounting group, or Tools → e-Tax Invoice…

  1. Choose the document: tax invoice, invoice/tax invoice, receipt/tax invoice, delivery order/tax invoice, Debit note (80) or Credit note (81). Document numbers count separately for each document type.
  2. Fill in the seller (once; it is remembered), for whom the Revenue Department requires the house number, province, district and subdistrict, and the buyer. A buyer is identified by tax ID and branch, Thai ID card or passport; 13-digit numbers are checked.
  3. For a debit or credit note, fill in Original invoice number, Original invoice date, Value before VAT and Original invoice type. Choose a Reason; for a code ending in 99, also fill in Reason details. The PDF shows the original value, correct value, difference and VAT on the difference.
  4. Type the items in the table. The Discount column is for a discount on each line; Bill discount reduces the whole bill. Enter discounts in baht, such as 50, or as a percentage, such as 10%. The amount before VAT, the VAT and the total, with the total in Thai words, show as you type. Tick Prices include VAT when the prices you type already include it.
  5. Press Create e-Tax Invoice and choose where to save. The next document number counts separately for each document type. For debit or credit notes, the button reads Create debit note or Create credit note.

Addresses and postcodes

  • Select Province, District and Subdistrict to fill in Postcode automatically. If a subdistrict has several postcodes, a list appears for you to choose from.
  • Type Postcode first to narrow down the province, district and subdistrict choices. You can always type or edit the postcode yourself; if it does not match the subdistrict, the app only warns you and still lets you use it.
  • Enter all five postcode digits from the data to set the province and narrow the district and subdistrict lists. This also applies to the seller. A postcode entered later takes precedence and clears districts or subdistricts that do not match it. If it matches the selected area, that selection stays; if the postcode is not in the data, the existing area stays and the app shows a warning.
  • Province, district and subdistrict names are always shown in Thai to match registered addresses. English mode explains this below the address fields.
  • The postcode data is stored in the app and works offline. It is from 2018 (B.E. 2561), so it may not reflect changes made since then.
  • For the buyer's address, choose between Thai address (separate fields) and Type the address yourself, for example for a buyer outside Thailand.

Sending it to the buyer:

  • e-Tax Invoice & e-Receipt: sign the file with your company's digital ID (Digital signature), then send it the way you registered with the Revenue Department.
  • e-Tax Invoice by Email: from the email address registered with the Revenue Department, send this one file to the buyer with a copy to csemail@etax.teda.th, with the subject written as the Revenue Department asks. The service stamps the time on it.

Testing before real use

  • Check the XML for free, with no registration: on the Revenue Department's etax.rd.go.th → Support → data structure check page, choose the XML taken out of the PDF.
  • e-Tax Invoice by Email: ask ETDA for a test at eservice@etda.or.th before sending for real.
YRK PDF e-Tax status
  • Follows ETDA standard ขมธอ. 3-2560, version 2.0
  • A sample XML file passed the structure check on the Revenue Department's validation page
  • It has never been tested by actually submitting to the e-Tax Invoice system
  • It is not certified by the Revenue Department
  • YRK PDF is not an e-Tax Invoice service provider. You must check the file and are responsible for submitting it yourself
Before using it for real: register with the Revenue Department first. In this version the XML is not signed separately (XAdES).

Drawings: DWG, measuring, counting

Opening AutoCAD drawings

DWG and DXF files open without AutoCAD. The drawing is shown like a PDF, at its scale, and layers can be shown or hidden in the sidebar's Layers tab.

Measuring

  • The Measure tab has Distance, Path, Area and Count.
  • Scale: From the drawing uses the scale stored in the file; or pick one; or press Calibrate and drag over a length you know.
  • Snap: catches line ends and middles of the drawing. Hold Shift for 45° steps.
  • For an area or a path, click each corner, then press Enter or double-click to finish.
  • Click a result's label to select it, then drag a corner to correct it. Delete removes it.
  • Add to document keeps the measurements in the file as comments.

Counting

Name a type, such as "Door" or "Light", and click each one on the drawing. Numbered marks are added; copy the list into Excel or save it as a file.

Comparing versions

Tools → Compare with another version… shows what changed between two revisions.

Rulers: Ctrl+R. They show millimetres on paper, or the drawing's units at its scale.

Passwords and redaction

Back up and import data

Open Settings → Privacy and safety… and choose Back up data… to save selected stamps, signature images, Digital IDs, trusted certificates, e-Tax settings, reading marks and general settings in an encrypted file. Choose a password of at least 12 characters and keep the file and password safe. The backup password cannot be recovered, and each Digital ID file has its own password.

Choose Import data…, select the backup, enter its password and press Check contents before Import data. The app first backs up your current data using the same password; if that backup cannot be verified, import stops. Close and reopen YRK PDF after importing.

Adding and removing a password

  • File → Protect with password… locks the whole file, or only printing and copying.
  • File → Remove password protection… saves a copy without the password (you need the password to open it).

Protecting an already signed file removes its signatures, and the app warns before doing it.

Redact (black out for good)

  1. On the Redact tab, drag over what must go, or press Mark search results to mark every place with the word in the search box.
  2. Check the marks, then press Apply redactions.
  3. The text, pictures and lines under the marks are removed, not just covered, and the result is saved as a new file.

Redaction also removes from the whole file:

  • Page thumbnails; document information and metadata (XMP); bookmarks; attachments; structure tags; XFA
  • Actions that run programs or send data (JavaScript, launching programs, submitting forms)
  • Pages where graphics cross a marked area are converted to an image, so their text can no longer be selected.
  • Annotations and links outside the marked areas are kept.

Editing, signing and redacting files with a password

  • In password-protected files you can edit and add text, sign digitally and redact. The result keeps the same passwords and restrictions.
  • The password is asked twice: when you first start changing the file, and each time before it is saved, signed or redacted, so nobody can change a file left open. With a wrong password nothing changes.
  • Files whose author forbids changes need the owner password.
Leaving your desk: asking again stops changes, not reading. Press Win+L to lock the computer.

Privacy

Everything happens on your computer: no file uploads, no usage statistics, and no AI. The program uses the internet for update checks and, only after asking you first, downloads OCR language data or the data needed to straighten scans automatically from the same designated source. It may also use the internet for digital-signature timestamps, certificate validation and revocation checks. It never sends document contents. The update check can be turned off in Settings → Privacy and safety…

Read the full privacy policy in the program at Help → Privacy policy (no internet needed), and on the YRK PDF website.

Saving, printing and updates

  • Save Ctrl+S: the new file is written in full first and only then replaces the old one, so a problem halfway cannot damage it.
  • Save a copy Ctrl+Shift+S: a new file; the original stays as it was.
  • Undo Ctrl+Z and Redo Ctrl+Y: for text edits, comments, form fields, measurements and page changes.
  • Print Ctrl+P. Pages per sheet fits 2, 4, 6 or 9 pages on one side of paper; Booklet orders the pages so that, printed on both sides (flipped on the short edge) and folded in half, they read as a book.
  • A dot • before the file name means there are unsaved changes. Closing always asks first.
  • If the program closes before you save (a power cut, say), the next start offers your changes back as "name (recovered).pdf" next to the original: a copy is kept every minute while there are unsaved changes.
  • When you save a signed file, the suggested file name does not repeat " (signed)" if the name already ends with it.

Updates

If update checks are allowed, a new version is downloaded for you and a button offers to restart into it. Every version is signed by the developer; a file whose signature does not check out is never installed. Updates are downloaded as full files, so they may be a bit larger. Check now in Settings → Updates…

Common problems and contact

Error dialogs and problem reports

The Error dialog shows a message, a code such as YRK-PAGE-006, and What you can do:. Try the suggested steps first. Look up the code in the Error codes appendix.

If the problem continues, press Copy info for problem report in the error dialog, or choose Help → Copy info for problem report. Review the information, then paste it into a message to the developer yourself. Nothing is sent automatically; error details are logged only on this computer.

Windows shows a SmartScreen warning when installing

The program does not have a paid developer certificate yet. Press More info, then Run anyway. Only download from the official website.

Search and copy find no text

The file is a scan. Run Recognize text (OCR) first.

Edited text is in a different font

The document's font is not installed on this PC, so a similar one is used. Install that font, or choose one in the bar at the top of the page.

Saving fails

The file may be open in another program. Your work is then saved under a new name next to it, so nothing is lost.
