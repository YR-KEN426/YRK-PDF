## YRK Easy PDF 1.0.3

**ใหม่**
- สร้างฟอร์ม PDF: ช่องข้อความ, ข้อความหลายบรรทัด, ช่องติ๊ก, รายการเลือก และช่องลายเซ็น
- แก้ไขหรือลบช่องฟอร์มที่บันทึกไว้แล้วได้
- แก้ข้อความ: เลือกฟอนต์ ขนาด ตัวหนา และตัวเอียงได้
- ไม้บรรทัดและการวัด: เลือกหน่วย (mm, cm, m, in, ft, pt) และสเกลได้จากมุมไม้บรรทัด โปรแกรมจำหน่วยไว้ให้
- เมนู เครื่องมือ → ข้อเสนอแนะและแจ้งปัญหา: ส่งความเห็นผ่านแบบฟอร์มหรืออีเมล (โปรแกรมไม่ส่งข้อมูลใดๆ เอง)

**แก้ไข**
- ข้อความที่แก้ไขด้วยฟอนต์ทดแทน มีขนาดใกล้เคียงต้นฉบับ

---

**New:** create PDF forms; edit or delete saved fields; font, size, bold and italic for edited text; ruler unit and scale; Suggestions and problems window (the app sends nothing itself).
**Fixed:** edited text in a substitute font matches the original size.
