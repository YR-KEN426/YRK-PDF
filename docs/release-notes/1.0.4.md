## YRK Easy PDF 1.0.4

**ใหม่**
- ลบหน้าแล้วกดเลิกทำ (Ctrl+Z) เพื่อนำหน้ากลับมาที่เดิมได้ และกดทำซ้ำ (Ctrl+Y) ได้
- แทรกหน้าจากไฟล์แล้วกดเลิกทำได้
- เลิกทำการหมุน ย้าย ลบ และแทรกหน้าได้หลายขั้นต่อเนื่องกัน

**แก้ไข**
- ปิดโปรแกรมโดยไม่บันทึกแล้วขึ้นข้อผิดพลาด "Cannot set Visibility…" แก้แล้ว

---

**New:** undo and redo for deleting pages and inserting pages from a file; page steps (rotate, move, delete, insert) can be undone one after another.
**Fixed:** an error when closing the app without saving.
