## YRK Easy PDF 1.0.5

**แก้ไข**
- แก้ปัญหาอัปเดตอัตโนมัติไม่ยอมติดตั้ง ("พบอัปเดต แต่ไม่ได้เซ็นรับรองโดย YRK") ที่เกิดกับรุ่น 1.0.3 และ 1.0.4 อัปเดตยังตรวจลายเซ็นของ YRK ทุกครั้งเหมือนเดิม
- หน้าต่างสร้างลายเซ็น: ข้อความตัวเลือก Digital ID ไม่ถูกตัดขอบเมื่อใช้เมนูภาษาอังกฤษ

**ใหม่**
- ลิงก์เว็บไซต์โปรแกรมในหน้า "เกี่ยวกับ" และหน้าต่าง "ข้อเสนอแนะและแจ้งปัญหา" (คำตอบสำหรับคำถามที่พบบ่อย)

หมายเหตุ: รุ่นนี้ดาวน์โหลดเป็นแพ็กเกจเต็ม (ประมาณ 73 MB) เพียงครั้งนี้ครั้งเดียว รุ่นถัดไปกลับมาเป็นอัปเดตขนาดเล็กตามเดิม
