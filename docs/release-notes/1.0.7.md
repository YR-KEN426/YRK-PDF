## YRK Easy PDF 1.0.7

**ใหม่**
- หน้าแรกแบบใหม่: เลือกเครื่องมือตามงานที่จะทำได้ทันที (รวม แยก แปลงไฟล์ แก้ไขและเซ็น งานแบบก่อสร้าง ความปลอดภัย) กดการ์ดแล้วเลือกไฟล์ โปรแกรมจะเปิดเครื่องมือนั้นให้เลย มีปุ่มเปลี่ยนภาษา ไทย | English และปุ่มหน้าแรกบนแถบเครื่องมือ
- PDF เป็น Word ดีขึ้นมาก: ตารางเป็นตาราง Word จริง (รวมช่อง เส้นขอบ สีพื้น) รูปภาพและกราฟอยู่ตำแหน่งเดิม ระยะบรรทัดและท้ายกระดาษเหมือน PDF
- PDF เป็น Excel ดีขึ้นมาก: ตารางมีช่องที่รวมกัน เส้นขอบ และสีพื้น ตัวเลขคำนวณได้และแสดงแบบเดิม เช่น 1,250.00 และ 3.0%
- PDF ที่สั่งพิมพ์จาก Excel (เช่น งบทดลอง): อ่านภาษาไทยได้ถูกต้อง เลขที่บัญชีกับชื่อบัญชีแยกคอลัมน์
- PDF เป็น PowerPoint: 1 หน้าเป็น 1 สไลด์ หน้าตาเหมือน PDF
- เครื่องมือมือจับสำหรับเลื่อนหน้า: กด Spacebar ค้างไว้ กด H หรือลากด้วยปุ่มกลางของเมาส์ (เหมือน Adobe)
- แถบฟอนต์ชุดเดียวสำหรับทุกข้อความ (เพิ่มข้อความ ช่องฟอร์ม แก้ไขข้อความ): เลือกฟอนต์ ขนาด ตัวหนา ตัวเอียง และสีได้ และเพิ่มปุ่ม "เพิ่มข้อความ" ในแท็บความคิดเห็น
- ลายน้ำ หัว/ท้ายกระดาษ และเลขหน้า เลือกฟอนต์ได้
- เมนูจัดใหม่: เครื่องมือ / ⚙ ตั้งค่า (ภาษา การอัปเดต ความเป็นส่วนตัว) / ? ช่วยเหลือ

**แก้ไข**
- ภาษาไทยในไฟล์ Word/Excel ที่แปลงมา มีช่องว่างแทรกก่อนสระ เช่น "จ ำกัด"
- ชื่อฟอนต์ไทย เช่น TH SarabunPSK ในไฟล์ Word ที่แปลงมาไม่ถูกต้อง ทำให้ Word ใช้ฟอนต์อื่นแทน

---

**New:** a start page with a card for each tool (click, choose a file, and the tool starts), language switch and a Home button; much better PDF to Word (real tables, pictures and charts in place, the PDF's spacing) and PDF to Excel (merged cells, borders, colours, number formats); PDFs printed from Excel read correctly; PDF to PowerPoint; hand tool (hold Space, H, or the middle mouse button); one font bar for all typed text (font, size, bold, italic, colour); fonts for watermarks and page numbers; Tools / Settings / Help menus.
**Fixed:** stray spaces before Thai vowels in exported files; Thai font names such as TH SarabunPSK in Word files.
