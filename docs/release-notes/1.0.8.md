## YRK PDF 1.0.8

**ชื่อใหม่**
- YRK Easy PDF เปลี่ยนชื่อเป็น **YRK PDF** พร้อมไอคอนใหม่ ทางลัดในเมนู Start และรายชื่อใน Windows เปลี่ยนชื่อให้เองเมื่ออัปเดต การตั้งค่าและลายเซ็นที่บันทึกไว้ยังอยู่ครบ
- โค้ดของโปรแกรมเปิดเผยแล้วที่ github.com/YR-KEN426/YRK-PDF (สัญญาอนุญาต Apache-2.0) ข้อความสัญญาอนุญาตของส่วนประกอบโอเพนซอร์สทั้งหมดดูได้ในหน้า เกี่ยวกับ

**ดีขึ้น**
- ค้นหาคำภาษาไทยในไฟล์ PDF ที่สั่งพิมพ์จาก Chrome หรือ Edge ได้แล้ว (เช่น "สัญญา") คัดลอกข้อความและแปลงเป็น Word/Excel ได้คำที่ถูกต้อง
- ตราประทับ "สำเนาถูกต้อง" บันทึกข้อความเป็นตัวอักษรจริง ค้นหาและคัดลอกได้
- ฟอร์มที่กรอกภาษาไทย: ฝังฟอนต์ Sarabun ไว้ในไฟล์ด้วย โปรแกรมอื่นที่แก้ช่องฟอร์มนั้นต่อจะมีฟอนต์ภาษาไทยใช้
- PDF เป็น Word: ตัดบรรทัดภาษาไทยตรงกับใน PDF และจัดตารางให้สูงเท่าเดิม แต่ละหน้าไม่ล้นไปหน้าถัดไป (รายงาน 22 หน้า ได้ Word 22 หน้า)
- ช่องฟอร์มรูปภาพ: ลบรูปที่บันทึกไว้แล้วได้ (ปุ่ม × บนรูป)
- ช่องฟอร์มที่วางแนวตั้ง: พิมพ์ตามแนวของช่อง และขนาดตัวอักษรอัตโนมัติพอดีช่อง

**แก้ไข**
- ข้อความไทยกับภาษาอังกฤษหรือตัวเลขติดกันเมื่อแปลงไฟล์ เช่น "ออมทรัพย์KBANK" "อายุ30"
- หน้าความเป็นส่วนตัว: บอกด้วยว่าเมื่อเปิด PDF ที่มีลายเซ็นดิจิทัล Windows จะตรวจสอบการเพิกถอนใบรับรองกับผู้ออกใบรับรอง

---

**New name:** YRK Easy PDF is now **YRK PDF**, with a new icon; shortcuts and the Windows apps list are renamed by the update, and settings and saved signatures are kept. The source code is open at github.com/YR-KEN426/YRK-PDF (Apache-2.0); all open-source license texts are in About.
**Better:** Thai words can be found, copied and exported in PDFs printed from Chrome or Edge; the certified-copy stamp's words are saved as real text; forms with Thai fields carry the Sarabun font for viewers that redraw them; PDF to Word breaks Thai lines where the PDF does, so pages run over less; a saved picture in an image field can be removed; turned form fields are typed and sized along their text.
**Fixed:** missing spaces between Thai and Latin text or numbers in exported files ("ออมทรัพย์KBANK"); the privacy page now mentions the certificate revocation check when a signed PDF opens.
