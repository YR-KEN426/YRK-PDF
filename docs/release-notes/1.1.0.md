## YRK PDF 1.1.0

**ใหม่**
- คู่มือการใช้งาน ภาษาไทยและอังกฤษ: กด F1 หรือ ช่วยเหลือ → คู่มือการใช้งาน เปิดในโปรแกรมได้เลย ไม่ต้องต่ออินเทอร์เน็ต
- แก้ไขข้อความ: กด Enter หรือคลิกที่อื่น ข้อความใหม่เข้าไปอยู่ในหน้าทันที และกด Ctrl+Z เอาข้อความเดิมคืนได้
- ช่องฟอร์มที่เพิ่งสร้างก็กด Ctrl+Z ย้อนกลับได้แล้ว

**ดีขึ้น**
- แก้ไขข้อความในตาราง: คลิกช่องไหนก็แก้เฉพาะช่องนั้น ช่องอื่นในแถวไม่ขยับ และคลิกในช่องว่างรอบตัวอักษรก็เลือกบรรทัดได้
- แก้ไขข้อความภาษาไทย: อ่านคำได้ถูกต้องเหมือนตอนคัดลอก เช่น สระอำที่บางไฟล์อ่านเป็น "ประจ ำปี" ตอนนี้เป็น "ประจำปี" (ใช้กับการคัดลอกและค้นหาด้วย)
- คลิกบรรทัดหรือวางกล่องเพิ่มข้อความแล้ว พิมพ์ได้ทันที ไม่ต้องคลิกซ้ำ
- หน้าต่างแคบ แถวปุ่มจะขึ้นบรรทัดใหม่แทนการซ้อนทับช่องค้นหา ข้อความสถานะ และปุ่มย้อนกลับ
- หลังสร้างช่องฟอร์ม แก้ข้อความ หรือย้อนกลับ หน้าจอยังอยู่ตำแหน่งเดิม

---

**New:** a user guide in Thai and English (F1, or Help → User guide), opened in the program and available offline; edited text goes into the page on Enter or a click outside, and Undo brings the old text back; new form fields can be undone too.
**Better:** editing in a table takes only the clicked cell; edited Thai reads as it does when copied (a sara am read as "ประจ ำปี" is now "ประจำปี", also for copy and search); new line editors and Add text boxes take typing at once; toolbars wrap instead of covering search, the status text and Undo; the view stays in place after a change reopens the document.
