## YRK PDF 1.1.3

**ใหม่**
- สำรองและลบ Digital ID แบบไฟล์ได้ (ต้องใส่รหัสผ่านของ ID) เอกสารที่เซ็นแล้วยังใช้ได้
- เมนูแทรก: รวมทุกอย่างที่เพิ่มลงในไฟล์ได้ไว้ที่เดียว ทั้งข้อความ รูปภาพ สัญลักษณ์ ลายเซ็น เส้น รูปทรง และหน้า (Alt+I)
- เส้นตรง (กด Shift เพื่อให้ไปทีละ 45°) และสัญลักษณ์ เช่น ✓ ✗ ☐ ☑ ● ★
- เพิ่มรูปภาพบนหน้า: เลือกไฟล์ วางจากที่คัดลอกไว้ (Ctrl+V) หรือลากไฟล์มาวาง แล้วย้ายและปรับขนาดได้ก่อนบันทึก
- ใบกำกับภาษีอิเล็กทรอนิกส์ (e-Tax Invoice): กรอกผู้ขาย ผู้ซื้อ และรายการ แล้วได้ไฟล์ PDF/A-3 ที่มีไฟล์ XML ตามมาตรฐาน ETDA ของกรมสรรพากรอยู่ข้างใน ใช้กับระบบ e-Tax Invoice & e-Receipt (เซ็นด้วยใบรับรองดิจิทัล) หรือ e-Tax Invoice by Email ได้ โปรแกรมจำข้อมูลผู้ขายและนับเลขที่เอกสารต่อให้
- จัดหน้าสแกน: ปรับหน้าที่เอียงให้ตรง ตัดขอบดำจากเครื่องสแกน และลบหน้าว่าง โปรแกรมตรวจทุกหน้าแล้วให้เลือกว่าจะแก้อะไร กดเลิกทำได้
- แยก PDF ตามบุ๊กมาร์ก: ได้ไฟล์ละบท ตั้งชื่อไฟล์ตามหัวข้อ
- เซ็นดิจิทัลและลบข้อมูลถาวรในไฟล์ที่มีรหัสผ่านได้แล้ว ไฟล์ที่ได้ใช้รหัสผ่านและข้อจำกัดเดิม
- ไฟล์ที่มีรหัสผ่านแก้ข้อความและเพิ่มข้อความได้แล้ว
- ถามรหัสผ่านตอนเริ่มแก้ไฟล์ครั้งแรก และถามอีกครั้งก่อนบันทึก เซ็น หรือลบข้อมูลถาวร กันคนอื่นแก้ไฟล์ที่เปิดค้างไว้

**แก้ไข**
- e-Tax: ที่อยู่ผู้ขายเลือกจังหวัด อำเภอ ตำบล และเบอร์โทรเขียนตามรูปแบบที่กรมสรรพากรกำหนด ไฟล์ XML ผ่านการตรวจ Schema และ Schematron ของกรมสรรพากร
- e-Tax: ไฟล์เป็น PDF/A-3U พร้อมข้อมูล XMP ตามที่ ETDA กำหนด รายการที่ไม่มีหน่วยใส่เฉพาะจำนวนใน XML และ VAT รายบรรทัดรวมตรงกับยอด VAT ของเอกสาร
- ไฟล์ที่ถูกจำกัดสิทธิ์: หมุน ย้าย หรือลบหน้าแล้วบันทึกด้วยรหัสผ่านเจ้าของ การเปลี่ยนหน้าเคยหายไป ตอนนี้บันทึกครบแล้ว

**New:** back up and delete digital ID files; an Insert menu with everything that can be added to a file; straight lines; symbols such as ✓ ✗ ☐ ☑; add pictures to a page (from a file, with Ctrl+V or by dropping a file), then move and resize them before saving; e-Tax Invoice (PDF/A-3 with the Revenue Department's ETDA XML inside, for e-Tax Invoice & e-Receipt or e-Tax Invoice by Email); clean up scans (straighten tilted pages, trim dark scanner edges, delete blank pages); split a PDF at its bookmarks; sign and redact password-protected files, keeping their passwords; edit text in protected files; the password is asked at the first edit and again before saving.
**Fixed:** on a file with restrictions, turned, moved or deleted pages were lost when saving with the owner password.
