## YRK PDF 1.1.5

**ใหม่**
- ช่วยเหลือ → สนับสนุนผู้พัฒนา… เปิดหน้าต่างในโปรแกรมพร้อม QR พร้อมเพย์ การเปิดหน้าต่างไม่ใช้อินเทอร์เน็ต ปุ่ม GitHub Sponsors เปิดเบราว์เซอร์เฉพาะเมื่อกดเท่านั้น
- นโยบายความเป็นส่วนตัวฉบับเต็มเปิดอ่านในโปรแกรมได้โดยไม่ต้องต่ออินเทอร์เน็ต จากเมนู ช่วยเหลือ → นโยบายความเป็นส่วนตัว และจากหน้าต่างความเป็นส่วนตัวและความปลอดภัย
- แท็บลายเซ็นมีปุ่ม "บันทึกฉบับก่อนเซ็น…" บันทึกเป็นไฟล์ใหม่ ไม่แตะไฟล์เดิม และบอกก่อนว่าลายเซ็นและการแก้ไขใดจะหายไป ใช้ไม่ได้กับไฟล์ที่ถูกเขียนใหม่ทั้งไฟล์ สำเนาที่ส่งให้ผู้อื่นไปแล้วยังมีลายเซ็นอยู่
- เตือนก่อนเซ็นไฟล์ที่เซ็นแล้ว

**เปลี่ยนแปลง**
- หน้าต่าง e-Tax คู่มือ และคำถามที่พบบ่อย บอกสถานะของ e-Tax ตรงๆ: ทำตามมาตรฐาน ETDA ขมธอ. 3-2560 v2.0, ไฟล์ XML ตัวอย่างผ่านการตรวจโครงสร้างของกรมสรรพากร, ยังไม่เคยทดสอบส่งจริง และไม่ได้รับการรับรองจากกรมสรรพากร
- ไฟล์ที่เซ็นแล้วไม่เสนอให้เซ็นรับรองเอกสาร (รับรองได้เฉพาะลายเซ็นแรก)
- ชื่อไฟล์ที่เสนอตอนบันทึกไฟล์ที่เซ็นไม่ต่อ " (signed)" ซ้ำ

**อัปเดต**
- รุ่นนี้เป็นรุ่นแรกที่การตรวจลายเซ็นอัปเดตแบบใหม่ของ 1.1.4 มีผลจริง: อัปเดตจาก 1.1.4 เป็น 1.1.5 จะถูกตรวจลายเซ็นของ YRK ทั้งไฟล์ก่อนติดตั้ง

---

**New**
- Help → Support the developer… opens an in-app window with the PromptPay QR code. Opening it needs no internet; the GitHub Sponsors button opens your browser only when you click it.
- The full privacy policy can be read inside the program, offline, from Help → Privacy policy and from the Privacy and safety window.
- The Signatures tab has a new "Save version before signing…" button. It saves a new file, never touches the original, and tells you which signatures and edits will be lost. It does not work on files that were rewritten as a whole. Copies already sent to others still carry the signature.
- A warning appears before signing a file that is already signed.

**Changed**
- The e-Tax window, the guide and the FAQ state the e-Tax status plainly: follows ETDA standard ขมธอ. 3-2560 v2.0; a sample XML file passed the Revenue Department's structure check; never tested by actually submitting; not certified by the Revenue Department.
- Certify is not offered when the file is already signed (only the first signature can certify).
- The file name suggested when saving a signed file no longer gets " (signed)" added twice.

**Updates**
- This is the first version where the update-signature check introduced in 1.1.4 takes effect: updating from 1.1.4 to 1.1.5 checks YRK's signature over the whole file before installing.
