## YRK PDF 1.1.6

**แก้ไข**
- เซ็นแบบเพิ่มข้อมูลตรวจสอบระยะยาว (LTV) ได้อีกครั้ง ใน 1.1.5 การเซ็นแบบนี้ไม่สำเร็จพร้อมข้อความว่าดาวน์โหลดรายการใบรับรองที่ถูกเพิกถอนไม่ได้ เพราะโปรแกรมไม่ยอมรับรายการรูปแบบใหม่ของ DigiCert ผู้ให้บริการประทับเวลา ตอนนี้ยอมรับตามมาตรฐาน RFC 5280 เฉพาะเมื่อรายการครอบคลุมใบรับรองนั้นครบ ไฟล์ที่เซ็นแบบ LTV แสดงสถานะการเพิกถอนได้โดยไม่ต้องต่ออินเทอร์เน็ต
- เมื่อเซ็นแบบ LTV ไม่สำเร็จ ข้อความบอกชัดว่าดาวน์โหลดไม่ได้ หรือดาวน์โหลดได้แต่ตรวจไม่ผ่าน และแถบ "กำลังเซ็น…" ปิดก่อนข้อความขึ้น
- นโยบายความเป็นส่วนตัวในโปรแกรม (ช่วยเหลือ → นโยบายความเป็นส่วนตัว) เปิดได้แล้ว ใน 1.1.5 ขึ้นข้อความว่าไม่พบไฟล์
- ถ้าการดาวน์โหลดอัปเดตหยุดกลางทางเกิน 5 นาที โปรแกรมจะหยุดรอ ขึ้นข้อความ และกดตรวจใหม่ได้ทันทีโดยไม่ต้องปิดโปรแกรม หน้าต่างเกี่ยวกับ YRK PDF แสดงเปอร์เซ็นต์การดาวน์โหลด

**ใหม่**
- หน้าต่าง e-Tax เติมรหัสไปรษณีย์ให้เองเมื่อเลือกตำบล (ข้อมูลในเครื่อง ไม่ต่อเน็ต ข้อมูลปี 2561 ตรวจและพิมพ์เองได้เสมอ) ตำบลที่มีหลายรหัสมีรายการให้เลือก พิมพ์รหัสก่อนจะช่วยกรองจังหวัด/อำเภอ/ตำบล และที่อยู่ผู้ซื้อกรอกแบบแยกช่องได้แล้ว (ยังพิมพ์เองได้ เช่น ที่อยู่ต่างประเทศ)
- ปุ่ม GitHub Sponsors ในหน้าต่างสนับสนุนผู้พัฒนาใหญ่และเห็นชัดขึ้น

**อัปเดต**
- ผู้ที่ใช้ 1.1.5 แล้วการดาวน์โหลดอัปเดตค้าง ให้ปิดแล้วเปิดโปรแกรมใหม่ แล้วกดตรวจหาการอัปเดตอีกครั้ง การหยุดรอเองจะมีผลตั้งแต่อัปเดตจาก 1.1.6 เป็นต้นไป

รหัสไปรษณีย์จาก thailand-geography-json (MIT) ซึ่งอ้างอิงโปสเตอร์รหัสไปรษณีย์ของไปรษณีย์ไทยปี 2561

---

**Fixed**
- Signing with long-term validation (LTV) works again. In 1.1.5 it failed with a message that the revocation list could not be downloaded, because the program did not accept the new list format of DigiCert, the timestamp provider. It now accepts it as RFC 5280 describes, only when the list fully covers the certificate. Files signed with LTV show their revocation status without an internet connection.
- When LTV signing fails, the message says whether the list could not be downloaded or was downloaded but could not be validated, and the "Signing…" bar closes before the message appears.
- The in-app privacy policy (Help → Privacy policy) opens again. In 1.1.5 it said the file was missing.
- If an update download stops for more than 5 minutes, the program stops waiting, shows a message, and you can check again right away without closing it. The About YRK PDF window shows the download percentage.

**New**
- The e-Tax window fills in the postcode when you pick a subdistrict (offline data from 2018; you can always check or type it yourself). Subdistricts with several postcodes show a list to choose from, typing a postcode first narrows the province/district/subdistrict lists, and the buyer address can now use separate fields (free text still available, e.g. for addresses abroad).
- The GitHub Sponsors button in the Support the developer window is larger and easier to see.

**Updates**
- If an update download gets stuck in 1.1.5, close and reopen the program, then check for updates again. The automatic stop applies to updates from 1.1.6 onward.
