## YRK PDF 1.1.9

**ใหม่**
- เชื่อถือผู้เซ็นที่ใช้ใบรับรองแบบรับรองตนเองได้จากแผงลายเซ็น หลังตรวจลายนิ้วมือ SHA-256 กับเจ้าของ การเชื่อถือมีผลเฉพาะใน YRK บนเครื่องนี้
- จัดการใบรับรองที่เชื่อถือได้: ดูรายการ นำเข้า `.cer` และลบใบรับรอง พร้อมดูและส่งออกใบรับรองสาธารณะของ Digital ID
- หมุนรูป ตรายาง และลายเซ็นที่วางได้ด้วยจุดจับหมุน (กด Shift เพื่อล็อกทีละ 15°) หรือหมุนตามเข็มนาฬิกา 90° และปรับความโปร่งใส 10–100% (ยกเว้นลายเซ็นที่นำเข้าจากไฟล์ PDF)


---

**New**
- Trust signers using self-signed certificates from the Signatures panel after checking the SHA-256 fingerprint with the owner. This trust applies only in YRK on this computer.
- Manage trusted certificates: view the list, import `.cer` files and remove certificates; view and export your Digital ID's public certificate.
- Rotate placed pictures, stamps and signatures with the rotation handle (hold Shift to snap to 15° steps) or rotate 90° clockwise, and adjust opacity from 10–100% (except signatures imported from PDF files).
