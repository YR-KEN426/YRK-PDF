## YRK PDF 1.2.0

**ใหม่**
- ออกใบเพิ่มหนี้ (80) และใบลดหนี้ (81) ได้ โดยกรอกเลขที่ วันที่ ประเภท และมูลค่าเดิมก่อนภาษีมูลค่าเพิ่มของใบกำกับภาษีเดิม พร้อมเลือกเหตุผลและระบุรายละเอียดเมื่อเลือกเหตุผลอื่น PDF แสดงมูลค่าเดิม มูลค่าที่ถูกต้อง ผลต่าง และ VAT ของผลต่าง เลขที่เอกสารนับแยกตามประเภทเอกสาร และนับต่อจากเลขล่าสุดที่เคยใช้
- กรอกส่วนลดแยกแต่ละรายการและส่วนลดท้ายบิลได้ ทั้งจำนวนบาท เช่น 50 หรือเปอร์เซ็นต์ เช่น 10%
- เมื่อเปิดไฟล์เดิมอีกครั้ง โปรแกรมกลับไปหน้าที่อ่านค้างไว้ โดยจำ 200 ไฟล์ล่าสุดไว้เฉพาะในเครื่องนี้ การล้างรายการไฟล์ล่าสุดจะล้างข้อมูลนี้ด้วย
- เชื่อถือลายเซ็นที่ใช้ใบรับรองแบบรับรองตนเองซึ่งใช้ RSA-PSS ได้ ปุ่ม “เชื่อถือใบรับรองนี้” จะแสดงเฉพาะใบรับรองที่รับรองตนเองจริง ลายนิ้วมือแบ่งแสดงเป็นกลุ่มละ 4 ตัว และรายการใบรับรองที่เชื่อถือได้ซึ่งยังว่างจะแนะนำวิธีเพิ่มใบรับรอง
- รูปภาพ ตรายาง ลายเซ็น และข้อความที่วางลงในเอกสารมีเครื่องหมาย YRK ที่มองไม่เห็นในไฟล์ โดยหน้ากระดาษยังดูเหมือนเดิม
- เพิ่ม Ko-fi ข้าง GitHub Sponsors ในหน้าต่างสนับสนุนและบนเว็บไซต์

**แก้ไข**
- สร้างคู่มือผู้ใช้ที่ติดไปกับรุ่นใหม่ทุกครั้ง รุ่น 1.1.8 และ 1.1.9 เคยมีคู่มือเก่าติดไปด้วย

**New**
- Create debit notes (80) and credit notes (81) by entering the original invoice number, date, type and value before VAT, then choosing a reason and adding details for an “Other” reason. The PDF shows the original value, correct value, difference and VAT on the difference. Document numbers count separately by type and continue from the last number you used.
- Enter discounts per line and on the whole bill, either as baht (such as 50) or a percentage (such as 10%).
- Reopening a file returns to the page you last read. The last 200 files are remembered on this computer only; clearing the recent files list clears this history too.
- Trust signatures using self-signed certificates with RSA-PSS. The “Trust this certificate” button appears only for truly self-signed certificates. Fingerprints are grouped in fours, and an empty trusted-certificates list explains how to add one.
- Pictures, stamps, signatures and text placed in a document carry an invisible YRK mark in the file; the page looks the same.
- Ko-fi is available beside GitHub Sponsors in the support window and on the website.

**Fixes**
- The user guide shipped with each release is now always rebuilt. Releases 1.1.8 and 1.1.9 included an old guide.
