## YRK PDF 1.2.3

**ใหม่**
- ลายน้ำหลายบรรทัด: กด Enter เพื่อขึ้นบรรทัดใหม่ หรือใช้พอดีหน้าเพื่อตัดบรรทัดที่ช่องว่าง สูงสุด 4 บรรทัด ลายน้ำอยู่ทับเนื้อหาโดยค่าเริ่มต้น
- แปลงเอกสารสแกนจาก PDF หรือรูปภาพเป็น PDF ที่ค้นหาข้อความได้ เอกสาร Word หรือข้อความ รองรับภาษาไทยและอังกฤษ ช่วยลดการพิมพ์ใหม่ พร้อมหน้าตรวจทานคำที่โปรแกรมไม่แน่ใจก่อนบันทึก
- คัดลอก ตัด และวางหน้าข้ามไฟล์ด้วย Ctrl+C/X/V บนภาพย่อหรือเมนูคลิกขวา วางทุกหน้าจากไฟล์ PDF ที่คัดลอกใน File Explorer ได้ มีคำเตือนก่อนปิดโปรแกรมหรือคัดลอกใหม่ทับหน้าที่ตัดไว้แต่ยังไม่ได้วาง
- เปิดหลายไฟล์พร้อมกันได้จากหน้าต่างเปิดไฟล์และการลากมาวาง แต่ละไฟล์อยู่ในแท็บของตัวเอง หากเกิน 20 ไฟล์จะถามยืนยันก่อน
- ที่คั่น 🔖: เพิ่มหรือแก้ผ่านปุ่มที่คั่น, Ctrl+D หรือเมนูคลิกขวาบนภาพย่อและหน้า เลือกได้ 6 สี คลิกรายการในแท็บที่คั่นเพื่อกลับไปอ่าน เก็บเฉพาะในเครื่อง ไม่เขียนลง PDF จึงใช้กับไฟล์มีลายเซ็นหรืออ่านอย่างเดียวได้ เลขหน้าเลื่อนตามการแก้หน้าหลังบันทึก รวมอยู่ในไฟล์สำรองข้อมูล และล้างพร้อมประวัติไฟล์ล่าสุด แยกจากบุ๊กมาร์กซึ่งเป็นโครงสารบัญใน PDF
- กล่องข้อผิดพลาดมีรหัสและคำแนะนำ พร้อมปุ่มคัดลอกข้อมูลเพื่อแจ้งปัญหา และรายการเดียวกันในเมนูช่วยเหลือ เพิ่มการดักข้อผิดพลาดที่ทำให้โปรแกรมหยุดทำงาน โดยเก็บ log ในเครื่อง ไม่มีรายงานถูกส่งอัตโนมัติ
- ปรับที่อยู่ e-Tax: รหัสไปรษณีย์ที่พิมพ์ทีหลังกำหนดจังหวัดและจำกัดรายการอำเภอ/ตำบล แม้เลือกพื้นที่ไว้ก่อนแล้ว ชื่อพื้นที่เป็นภาษาไทยเสมอ พร้อมหมายเหตุในโหมดอังกฤษ ปรับข้อความไทย/อังกฤษให้สอดคล้องกัน และให้หน้าต่างลายเซ็นดิจิทัลใช้ได้บนจอเล็ก

**หมายเหตุ**
- ตรวจผล OCR ก่อนใช้ทุกครั้ง โดยเฉพาะชื่อ ตัวเลข วันที่ และจำนวนเงิน ภาพเบลอ เอียง ตัวเล็ก หรือลายมืออาจอ่านผิดได้ คำที่ไม่ถูกทำเครื่องหมายก็อาจผิดได้ แนะนำสแกนที่ 300 dpi และวางกระดาษตรง
- การทำ PDF ที่มีรหัสผ่านให้ค้นหาข้อความได้ยังไม่รองรับ ให้บันทึกสำเนาที่ไม่มีรหัสผ่านก่อน ควรแปลงเอกสารก่อนเซ็นไฟล์ผลลัพธ์
- ข้อความลายน้ำภาษาไทยที่ไม่มีช่องว่างตัดบรรทัดอัตโนมัติไม่ได้ ให้กด Enter แบ่งบรรทัดเอง
- การเลิกทำแยกตามไฟล์ หากต้องการคืนหน้าที่ตัด ให้กด Ctrl+Z ในไฟล์ต้นทาง และควรวางพร้อมบันทึกไฟล์ปลายทางก่อนปิดโปรแกรม

## YRK PDF 1.2.3

**New**
- Multi-line watermarks: press Enter for a new line, or use Fit the page to wrap at spaces, up to four lines. Watermarks appear over page content by default.
- Convert scanned PDFs or images to searchable PDF, editable Word or text. Thai and English OCR helps reduce retyping, with a review screen for uncertain words before saving.
- Copy, cut and paste pages across files with Ctrl+C/X/V on thumbnails or the context menu. Paste all pages from a PDF copied in File Explorer. Warnings appear before closing the app or replacing an unpasted cut with a new copy.
- Open several files at once from the Open dialog or by dragging them into the app, each in its own tab. Opening more than 20 files asks for confirmation.
- Reading marks 🔖: add or edit using the toolbar button, Ctrl+D or the context menu on thumbnails and pages. Choose from six colours and return to a page from the Reading marks tab. Marks stay on this computer without changing the PDF, so they work with signed and read-only files. Page numbers follow page edits when saved. Marks are included in backups and cleared with recent-file history. They are separate from the PDF's bookmark outline.
- Error dialogs show a code, suggested actions and a Copy info for problem report button, also available in Help. Added handlers for unexpected errors that can stop the app. Logs stay on this computer; reports are never sent automatically.
- Updated e-Tax addresses: a postcode entered later sets the province and filters districts/subdistricts, even after areas have been selected. Area names remain in Thai, with a note in English mode. Improved Thai/English UI consistency and made the digital signature dialog fit small screens.

**Note**
- Always check OCR output before using it, especially names, numbers, dates and amounts. Blurry, tilted, small or handwritten text can be misread. Unmarked words can be wrong too. Scan at 300 dpi with the page straight.
- Making password-protected PDFs searchable is not supported yet; save an unprotected copy first. Convert documents before signing the output.
- Thai watermark text without spaces cannot wrap automatically. Press Enter to split it into lines.
- Undo is separate for each file. To restore cut pages, press Ctrl+Z in the source file. Paste and save the destination file before closing the app.
