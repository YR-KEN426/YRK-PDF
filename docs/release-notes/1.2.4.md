## YRK PDF 1.2.4

**ใหม่**
- หน้าแรกแบบใหม่: ซ่อนปุ่มเอกสารบนแถบด้านบนเมื่ออยู่หน้าแรก พร้อมโลโก้ ปุ่มภาษา ไทย|EN ช่องค้นหาเครื่องมือกลางหน้า (Ctrl+F) กล่องลากไฟล์ PDF, DWG, DXF และ AI มาวาง และปุ่มเปิดไฟล์
- การ์ดเครื่องมือมี 2 มุมมอง: “เครื่องมือที่ใช้บ่อย” 8 ใบ และ “ทั้งหมด” ที่แยกตามหมวดพร้อมแท็บหมวด การ์ดมีคำอธิบายสั้นและ tooltip คำอธิบายเต็ม และรองรับชื่อยาว 2 บรรทัด
- แผงไฟล์ล่าสุดบนหน้าแรกแสดงเวลาเปิดล่าสุด โดยเก็บใน recent-times.json เฉพาะในเครื่อง ปิดการแสดงไฟล์ล่าสุดบนหน้าแรกได้ในหน้าต่างความเป็นส่วนตัว เมนูไฟล์ “ล้างรายการ” ล้างที่คั่นและตำแหน่งที่อ่านค้างด้วย
- ปรับ ComboBox, ปฏิทิน/DatePicker, แท็บ และวงเลือกสีให้ใช้สไตล์เดียวกันทั่วโปรแกรม รวมสีไว้ในไฟล์สีกลางเพื่อเตรียมโหมดมืดในรุ่นถัดไป
- ฟอร์ม e-Tax จัดเป็นการ์ด 4 ใบ (เอกสาร ผู้ขาย ผู้ซื้อ รายการ) พร้อมแถบยอดสุทธิตัวใหญ่ด้านล่างหน้าต่าง แถวแรกไม่ถูกหัวหน้าต่างตัด แถวใหม่ในตารางเป็นสีอ่อน และกดสร้างทันทีหลังแก้ช่องสุดท้ายในตารางได้โดยใช้ค่าล่าสุด การคำนวณและ XML ไม่เปลี่ยน
- ตรายางเพิ่มทรงริบบิ้น (Ribbon) และตราวงกลมคู่ (Seal) จัดข้อความไว้กลางตรา เหลือช่องวันที่ช่องเดียว เลือกสีหมึกด้วยวงเลือกสี และตราที่เลือกมีกรอบหนา ตราทรงใหม่รวมในไฟล์สำรองข้อมูลและนำเข้าได้ ส่วนตราที่บันทึกจากรุ่นเก่ายังเปิดได้
- แก้ข้อผิดพลาดการแสดงผลเล็กน้อยที่พบระหว่างทดสอบหน้าต่าง

**หมายเหตุ**
- ภาพหน้าจอในคู่มือจะอัปเดตในรุ่นถัดไป
- เมื่อนำตราทรงใหม่กลับไปเปิดในรุ่นเก่า จะแสดงเป็นกรอบสี่เหลี่ยม แต่ตรายังคงอยู่

## YRK PDF 1.2.4

**New**
- New home page: document buttons are hidden from the top bar on the home page, which shows the logo, Thai|EN language buttons, a centered tool search (Ctrl+F), a drop area for PDF, DWG, DXF and AI files, and an Open button.
- Tool cards have two views: “Frequently used” (8 cards) and “All”, grouped by category with category tabs. Cards have a short description and a tooltip with the full description, and support two-line long names.
- The home page's recent files panel shows when each file was last opened, stored locally in recent-times.json. You can hide recent files on the home page in the Privacy window. File → “Clear list” also clears reading marks and last-read positions.
- ComboBox, calendar/DatePicker, tabs and colour wheels now share one style throughout the app. Colours are gathered in a central colour file in preparation for dark mode in a future release.
- The e-Tax form is arranged in four cards (Document, Seller, Buyer and Items), with a large net total bar at the bottom of the window. The first row is no longer clipped by the title bar, new table rows have a light colour, and Create immediately after editing the last table field uses the edited value. Calculation and XML are unchanged.
- Rubber stamps add Ribbon and double-circle Seal shapes, with text centered in the stamp, one date field, an ink colour wheel and a thick border around the selected stamp. New shapes are included in and can be imported from backup files. Stamps saved in older versions still open.
- Fixed minor display issues found while testing windows.

**Note**
- The screenshots in the guide will be updated in a future release.
- New stamp shapes appear as a rectangle when opened in an older version, but the stamp remains.
