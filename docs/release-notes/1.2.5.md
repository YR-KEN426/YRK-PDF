## YRK PDF 1.2.5

**ใหม่**
- โหมดมืด: ไปที่ ตั้งค่า → ธีม แล้วเลือก ตามระบบ, สว่าง หรือ มืด ค่าเริ่มต้นคือ ตามระบบ และเปลี่ยนตาม Windows ได้ทันทีขณะเปิดโปรแกรม หัวหน้าต่างเปลี่ยนเป็นสีมืดตามธีม เมื่อเปิด High Contrast ของ Windows โปรแกรมใช้สีของระบบ ส่วนหน้า PDF และพื้นกระดาษ เช่น กรอบวาดลายเซ็นและตัวอย่าง ยังคงเป็นสีขาวเสมอ
- เปลี่ยนสีหลักของโปรแกรมเป็นสีแดง YRK ข้อความแจ้งข้อผิดพลาดใช้สีส้มอำพันเพื่อให้แยกจากสีหลักชัดเจน กรอบโฟกัสเมื่อใช้คีย์บอร์ดยังคงเป็นสีน้ำเงิน สีข้อความกับพื้นหลังอ่านง่ายตามมาตรฐาน contrast 4.5:1 ทั้งธีมสว่างและมืด
- เพิ่มแถบสถานะด้านล่างเอกสาร แสดงข้อความสถานะทางซ้าย และปุ่มก่อนหน้า/ถัดไป ช่องเลขหน้า และซูมทางขวา ซึ่งย้ายมาจากแถบด้านบน แถบนี้ซ่อนบนหน้าแรก และแถบเครื่องมือด้านบนไม่ล้นเมื่อหน้าต่างกว้าง 1280 พิกเซล
- ช่องค้นหาในเอกสารขยายกว้างขึ้นเมื่อคลิกหรือกด Ctrl+F และหดกลับเมื่อเลิกใช้ หากหน้าต่างแคบ ช่องค้นหาจะแสดงเป็นปุ่มไอคอน
- ใช้กล่องคำถามรูปแบบเดียวกันทั่วโปรแกรม พร้อมปุ่มตามภาษาที่เลือกและตัวอักษรลัด (Alt+ตัวอักษร) กด Esc หรือปุ่มปิดหน้าต่างเพื่อยกเลิกได้เสมอ ปุ่มที่เน้นคือปุ่มที่จะทำงานเมื่อกด Enter คำถามที่อาจลบข้อมูลหรือทิ้งงานจะตั้งปุ่มเริ่มต้นเป็นยกเลิก และอ่านข้อความยาวได้ด้วยการเลื่อน
- เพิ่มปุ่ม “ล้างรายการ” บนแผงไฟล์ล่าสุดหน้าแรก ทุกช่องทางที่ล้างรายการ ทั้งหน้าแรก เมนูไฟล์ล่าสุด และหน้าต่างความเป็นส่วนตัว ใช้กล่องยืนยันเดียวกัน รายการไฟล์ล่าสุดและเวลาเปิดจะถูกล้างเสมอ เลือกได้ว่าจะล้างตำแหน่งที่อ่านค้าง (ติ๊กไว้เริ่มต้น) และที่คั่นหนังสือ (ไม่ติ๊กเริ่มต้น) ด้วยหรือไม่ รวมถึงของไฟล์ที่เปิดอยู่ Enter, Esc หรือปิดกล่อง = ยกเลิก เมื่อล้างตำแหน่ง โปรแกรมจะไม่บันทึกตำแหน่งอ่านค้างจนกว่าจะเลื่อนหน้าเองหรือเปิดไฟล์ใหม่ และจะแจ้งหากล้างข้อมูลที่เลือกไม่ครบ
- ปรับการแสดงผลบนจอเล็กและเมื่อขยาย 125–200% ให้ดีขึ้น หน้าต่างหลักและหน้าต่างใหญ่ เช่น สแกน พิมพ์ แปลงเอกสารสแกน และตรวจ OCR จะย่อให้พอดีกับพื้นที่ของจอที่เปิดอยู่ เนื้อหาเลื่อนได้แทนการถูกตัด รวมถึงเมื่อย้ายหน้าต่างไปจออื่น

**แก้ไข**
- นำเข้าลายเซ็นจากรูปถ่ายที่มีเงาหรือแสงไม่เท่ากันได้ดีขึ้น โดยแยกเส้นลายเซ็นออกจากกระดาษได้แม่นยำขึ้น และเพิ่มคำแนะนำการถ่ายรูปในแท็บนำเข้า
- ปรับการบันทึกการตั้งค่าไม่ให้ทับกันเมื่อหลายหน้าต่างบันทึกพร้อมกัน หากไฟล์ตั้งค่าเสีย โปรแกรมจะสำรองไฟล์ไว้ก่อนและไม่เขียนทับ ค่าที่มาจากรุ่นใหม่กว่าจะไม่หายเมื่อเปิดด้วยรุ่นนี้
- ปรับคู่มือภาษาไทยและอังกฤษให้ตรงกับโปรแกรม ทั้งชื่อปุ่มและเมนู คีย์ลัด ตำแหน่งใหม่ของเลขหน้าและซูม ธีม และการล้างรายการ พร้อมลบภาคผนวกที่ซ้ำในคู่มือภาษาอังกฤษ

**หมายเหตุ**
- ภาพหน้าจอในคู่มือยังเป็นหน้าตาเดิม และจะอัปเดตในรุ่นถัดไป
- รุ่นนี้เป็นรุ่นสุดท้ายที่เพิ่มความสามารถใหม่ก่อนลง Microsoft Store รุ่นถัดไปจะเน้นตรวจสอบและแก้ไข

## YRK PDF 1.2.5

**New**
- Dark mode: Go to Settings → Theme and choose Follow system, Light, or Dark. The default is Follow system, and the app changes with Windows immediately while it is open. The title bar follows the dark theme. When Windows High Contrast is on, the app uses system colours. PDF pages and paper areas, such as the signature drawing frame and preview, always stay white.
- The app's primary colour is now YRK red. Error messages use amber to stand out clearly from the primary colour. Keyboard focus outlines remain blue. Text and background colour combinations meet the 4.5:1 contrast standard in both light and dark themes.
- A new status bar appears below the document. It shows status text on the left, with Previous/Next buttons, the page number field, and zoom on the right. These have moved from the top bar. The status bar is hidden on the home page, and the top toolbar no longer overflows at a window width of 1280 pixels.
- The document search field expands when clicked or when you press Ctrl+F, then shrinks when you stop using it. In a narrow window, search becomes an icon button.
- Questions now use the same dialog throughout the app, with buttons in the selected language and keyboard shortcuts (Alt+letter). Esc or the close button always cancels. The highlighted button is the one activated by Enter. Questions that may delete information or discard work default to Cancel, and long messages can be read by scrolling.
- A “Clear list” button is now available on the home page's recent files panel. The home page, Recent files menu and Privacy window share one confirmation dialog. The recent files list and opening times are always cleared; choose whether to also clear saved reading positions (checked by default) and reading marks (unchecked by default), including data in open tabs. Enter, Esc or closing the dialog cancels. After clearing positions, the app will not save a last-read position until you navigate yourself or explicitly open a file. The app reports if it cannot clear everything selected.
- Improved display on small screens and at 125–200% scaling. The main window and large windows such as Scan, Print, Convert scanned document and OCR review shrink to fit the available area of the screen they are on. Content can be scrolled instead of being clipped, including after moving a window to another screen.

**Fixed**
- Improved signature import from photos with shadows or uneven lighting, with better separation of signature strokes from the paper and photo-taking tips in the Import tab.
- Settings no longer overwrite one another when multiple windows save at the same time. If a settings file is damaged, the app backs it up first and does not overwrite it. Values from a newer version are preserved when opened in this version.
- Updated the Thai and English guides to match the app, including button and menu names, keyboard shortcuts, the new page number and zoom locations, themes, and clearing the list. Removed the duplicate appendix from the English guide.

**Note**
- The screenshots in the guides still show the old appearance and will be updated in the next release.
- This is the last release to add new features before the Microsoft Store release. The next release will focus on checks and fixes.
