FAQ

Questions?

Is it really free? Are there hidden costs?

Every feature is free. There is no paid edition, no trial that expires and no advertising, and you never need a credit card or an account.

Can I use it at work or in a company?

Yes. It is free for personal, work and business use, on as many computers as you like.

Is it safe? Are my documents sent anywhere?

Documents are opened and edited only on your computer. The program never sends documents to an AI or cloud service (OCR runs on your computer with Tesseract), collects no statistics and never uploads documents. The details are on the “Privacy and safety” page in the program. “No AI” describes what the program does with your documents; the program's code was written with the help of AI coding tools, and the developer tests and maintains it.

Why does the installer show a blue “Windows protected your PC” screen?

The screen comes from Microsoft Defender SmartScreen, which often warns about programs that have no “publisher certificate” (code signing certificate) yet, or that few people have downloaded so far. The certificate is a paid yearly service, so free programs from small developers often don't have one, and Windows shows the publisher as “Unknown publisher”.

The warning does not mean a virus was found; it means Windows can't yet confirm who made the program. If Microsoft Defender really found a virus, it would report a threat and quarantine the file instead.

The decision to install is yours. If you downloaded it from this page or from github.com/YR-KEN426 and checked the file as described in the next question, you can continue with More info and then Run anyway. If the file came from somewhere else, for example passed around in a chat, don't open it; download it again from this page.

How can I check the file before installing?

There are two ways, and you can do both:

1. Scan it with Windows Security: right-click YRK.EasyPdf-win-Setup.exe and choose “Scan with Microsoft Defender” (in Windows 11 it is under “Show more options”).

2. Compare the file's fingerprint (SHA-256): this checks that your file is byte for byte the one we published. Open PowerShell in your download folder, type Get-FileHash .\YRK.EasyPdf-win-Setup.exe and compare the result with the sha256 value of that file on the latest release page (upper or lower case doesn't matter). If they match, your file is the very file we published, not changed or swapped on the way.

Note: comparing SHA-256 only confirms that the file matches the published release; it does not scan for viruses. For that, use way 1.

Why does it install without administrator rights?

It installs only for your user account (in the AppData folder) and doesn't touch Windows system files, so it needs no administrator rights. With one exception: if the computer lacks the Microsoft Visual C++ Runtime that OCR needs, the installer asks for rights to install that Microsoft component.

Are automatic updates safe? What if someone fakes an update?

Every update is signed with YRK's private key, which exists only on the developer's computer. Your copy of the program contains the matching public key and installs only updates whose signature matches. If someone changed an update file on the web, the signature would not match and the program would not install it. The program also asks on first start whether it may check for updates, and installs nothing until you click “Restart to update”.

My antivirus warns about it. What should I do?

A warning can have several causes, for example a new program without a publisher certificate, or a file that was changed on the way. Stop the installation first, then check that you downloaded it from this page and that the SHA-256 value matches the release page.

Then tell us which antivirus it is, the name of the threat it reported, and the version of the file. We will look into it and get back to you.

Do I need an internet connection?

No. Every feature works offline, except OCR in a language that isn't on your computer yet: its language file is downloaded the first time. Apart from that, the internet is used only to check for updates (if you allow it) and to timestamp a digital signature (if you choose to).

Does it work on a Mac or a phone?

For now it runs only on Windows 10 and 11 computers (64-bit).

Does it really open AutoCAD files? Do I need AutoCAD?

It opens .dwg and .dxf files directly, without AutoCAD. The program converts the drawing to a PDF on your computer, with its layers and scale. Drawings that use special fonts or some special objects may look slightly different from AutoCAD.

How do I update the program?

If you allow update checks, the program downloads a new version by itself and shows a “Restart to update” button; nothing is installed until you click it. You can also download the installer from this page again.

How do I uninstall it?

Go to Windows Settings → Apps, choose YRK PDF and click Uninstall. For the portable version, just delete its folder.
