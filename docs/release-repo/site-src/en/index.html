General

Is it really free? Any hidden costs?+

Every feature is free. There is no paid version, no trial that runs out, no ads, and no credit card or account needed.

Can I use it at work or in a company?+

Yes. It is free for personal use, at work and in companies, on any number of computers.

Does it work on a Mac or a phone?+

For now it runs only on 64-bit Windows 10 and 11.

Does it need the internet?+

No. Everything works offline, except OCR in a language not on your computer yet, which downloads that language once. Otherwise it goes online only to check for updates (if you allow it) and to timestamp a digital signature (if you choose to).

What is the difference between the installer and the zip?+

The installer adds icons on the desktop and in the Start menu. The zip needs no installing: unzip it and open the program, and delete the folder when you are done with it. Both update themselves.

Installing and safety

Why does a blue “Windows protected your PC” screen appear?+

It comes from Microsoft Defender SmartScreen, which warns about programs without a publisher certificate (code signing). The certificate is a yearly purchase that free programs from small developers often don't have yet, so Windows shows “Unknown publisher”.

The warning does not mean a virus was found. If you downloaded from this page or from github.com/YR-KEN426, click More info, then Run anyway. If the file came from anywhere else, such as a chat, don't open it: download it again from this page.

How do I check the file before installing?+

1. Scan it: right-click the file and choose “Scan with Microsoft Defender” (on Windows 11 it is under “Show more options”).

2. Compare its fingerprint (SHA-256): open PowerShell in your Downloads folder, type Get-FileHash .\YRK.EasyPdf-win-Setup.exe and compare the result with the sha256 value on the latest release page. If they match, it is the same file we published.

My antivirus warns about it. What should I do?+

Stop installing first. Check that you downloaded it from this page and that the SHA-256 matches, then tell us the antivirus name, the threat name it shows and the file's version. We will look into it and reply.

Why does it install without administrator rights?+

It installs only into your own user account (the AppData folder) and doesn't touch system files. The one exception: on a computer without the Microsoft Visual C++ Runtime that OCR needs, the installer asks for permission to install that Microsoft component.

Are my documents sent anywhere?+

No. Documents are opened and edited only on your computer, never sent to AI or cloud services (OCR runs on your computer), and no usage statistics are collected. See the details in the program: Settings → Privacy and safety.

Are automatic updates safe? What if someone fakes one?+

Every update is signed with the developer's key, and the program installs only updates whose signature matches the key built into it. If someone changes an update file, the signature no longer matches and the program won't install it.

Using it

How do I combine files, or take some pages out?+

Open the program, choose “Combine PDF” or “Split PDF” on the start page, then pick your files. The result is saved as a new file; your original stays as it was.

How much text can I edit in a PDF?+

You can edit Thai and English text and choose the font and size. It is meant for fixing words or short lines, not for laying out a whole page again.

I converted to Word and got only pictures, no text+

That is usually a scanned file, which holds only images. Run OCR first, then convert to Word or Excel. Converting works best on documents with real text.

Where are saved signatures kept? Are they safe?+

If you choose to keep a signature for next time, it is encrypted and stored only on this computer.

What is the difference between a signature and a Digital ID signature?+

A signature is a picture of your handwriting placed on the document. A Digital ID signature proves who signed and shows if anyone changes the document afterwards.

If I redact something, is my original file lost?+

No. The result is saved as a new file, and the redacted content is really removed from that new file. The original doesn't change.

Drawings

Does it really open AutoCAD files? Do I need AutoCAD?+

It opens .dwg and .dxf files directly, without AutoCAD, with their layers and scale. Drawings with special fonts or objects may look slightly different from AutoCAD.

What can I measure on a drawing?+

Lengths, lengths along a line, and areas at the drawing's scale, and you can count items on the drawing, such as lights and sockets. Drag a corner to correct a measurement, or press Ctrl+Z to undo it.

Can I send a drawing to someone without CAD software?+

Yes. Save it as a PDF and send that. Each layout becomes a PDF page at its real scale.

Updates and feedback

How do I update the program?+

If you allow update checks, the program downloads a new version by itself and then shows a “Restart to update” button. Nothing is installed until you click it. You can also download the installer from this page again.

How do I uninstall it?+

Go to Windows Settings → Apps, choose YRK PDF → Uninstall. For the zip, just delete the folder.

I'm stuck, or I'd like a new feature. Where do I tell you?+

In the program: Help → Suggestions and problems. Or use the feedback form (no sign-in), or email yrken.official@gmail.com.
