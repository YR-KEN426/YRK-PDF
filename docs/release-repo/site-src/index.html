คำถามที่พบบ่อย

กดที่คำถามเพื่อดูคำตอบ ไม่เจอคำตอบที่ต้องการ ถามเราได้

ทั่วไปติดตั้งและความปลอดภัยการใช้งานงานเขียนแบบอัปเดตและแจ้งปัญหา

ทั่วไป

ฟรีจริงไหม มีค่าใช้จ่ายแอบแฝงหรือเปล่า+

ฟรีจริงทุกความสามารถ ไม่มีรุ่นเสียเงิน ไม่มีรุ่นทดลองที่หมดอายุ ไม่มีโฆษณา และไม่ต้องใส่บัตรเครดิตหรือสมัครบัญชี

ใช้ในบริษัทหรือในงานได้ไหม+

ได้ ใช้ได้ฟรีทั้งส่วนตัว ในงาน และในบริษัท ติดตั้งได้ไม่จำกัดจำนวนเครื่อง

ใช้กับ Mac หรือมือถือได้ไหม+

ตอนนี้รองรับเฉพาะคอมพิวเตอร์ Windows 10 และ 11 แบบ 64 บิต

ต้องต่ออินเทอร์เน็ตไหม+

ไม่ต้อง ทุกความสามารถใช้แบบออฟไลน์ได้ ยกเว้น OCR ภาษาที่ยังไม่มีในเครื่อง ซึ่งต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อดาวน์โหลดไฟล์ภาษา นอกจากนั้นใช้อินเทอร์เน็ตเฉพาะตอนตรวจอัปเดต (ถ้าอนุญาต) และประทับเวลาลายเซ็นดิจิทัล (ถ้าเลือก)

แบบติดตั้ง กับแบบไม่ต้องติดตั้ง (zip) ต่างกันอย่างไร+

แบบติดตั้งจะสร้างไอคอนบนเดสก์ท็อปและเมนูเริ่ม แบบ zip แตกไฟล์แล้วเปิดโปรแกรมได้เลย เหมาะกับเครื่องที่ไม่อยากติดตั้งอะไรเพิ่ม เลิกใช้ก็ลบโฟลเดอร์ทิ้งได้ทันที ทั้งสองแบบอัปเดตเองได้

ติดตั้งและความปลอดภัย

ทำไมตอนติดตั้งขึ้นหน้าจอสีน้ำเงิน “Windows ให้การปกป้องพีซีของคุณแล้ว”+

หน้าจอนี้มาจาก Microsoft Defender SmartScreen ซึ่งเตือนโปรแกรมที่ยังไม่มี “ใบรับรองผู้เผยแพร่” (code signing) ใบรับรองนี้ต้องซื้อรายปี โปรแกรมฟรีจากผู้พัฒนารายเล็กจึงมักยังไม่มี Windows จึงแสดงว่า “ผู้เผยแพร่ที่ไม่รู้จัก”

การเตือนนี้ไม่ได้แปลว่าพบไวรัส ถ้าดาวน์โหลดจากหน้านี้หรือจาก github.com/YR-KEN426 กด “ข้อมูลเพิ่มเติม” แล้ว “ยืนยันการเรียกใช้” ได้ (Windows ภาษาอังกฤษ: More info แล้ว Run anyway) ถ้าได้ไฟล์มาจากที่อื่น เช่น ส่งต่อกันในแชต อย่าเปิด ให้ดาวน์โหลดใหม่จากหน้านี้

ตรวจสอบไฟล์ก่อนติดตั้งอย่างไร+

1. สแกนไวรัส: คลิกขวาที่ไฟล์ แล้วเลือก “Scan with Microsoft Defender” (Windows 11 อยู่ใน “Show more options”)

2. เทียบลายนิ้วมือไฟล์ (SHA-256): เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด พิมพ์ Get-FileHash .\YRK.EasyPdf-win-Setup.exe แล้วเทียบกับค่า sha256 ในหน้ารายละเอียดรุ่นล่าสุด ถ้าตรงกัน แปลว่าเป็นไฟล์เดียวกับที่เราเผยแพร่

โปรแกรมแอนตี้ไวรัสของฉันเตือน ทำอย่างไรดี+

หยุดติดตั้งก่อน ตรวจว่าดาวน์โหลดจากหน้านี้และค่า SHA-256 ตรงกัน แล้วแจ้งเราพร้อมชื่อโปรแกรมแอนตี้ไวรัส ชื่อภัยคุกคามที่แสดง และรุ่นของไฟล์ เราจะตรวจสอบและตอบกลับ

ทำไมติดตั้งได้โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ+

โปรแกรมติดตั้งเฉพาะในบัญชีผู้ใช้ของคุณ (โฟลเดอร์ AppData) ไม่แตะไฟล์ระบบ ยกเว้นเครื่องที่ยังไม่มี Microsoft Visual C++ Runtime สำหรับ OCR ตัวติดตั้งจะขอสิทธิ์เพื่อติดตั้งส่วนนี้ของ Microsoft

เอกสารของฉันถูกส่งไปที่ไหนหรือเปล่า+

ไม่ เอกสารเปิดและแก้ในเครื่องของคุณเท่านั้น ไม่ส่งให้บริการ AI หรือคลาวด์ (OCR ทำในเครื่อง) ไม่เก็บสถิติการใช้งาน รายละเอียดดูได้ในโปรแกรม: ตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย

อัปเดตอัตโนมัติปลอดภัยไหม ถ้ามีคนปลอมอัปเดตล่ะ+

อัปเดตทุกครั้งเซ็นด้วยกุญแจของผู้พัฒนา และโปรแกรมจะติดตั้งเฉพาะอัปเดตที่ลายเซ็นตรงกับกุญแจที่ฝังไว้ ถ้ามีคนแก้ไฟล์อัปเดต ลายเซ็นจะไม่ตรงและโปรแกรมจะไม่ติดตั้ง

การใช้งาน

รวมหลายไฟล์ หรือแยกบางหน้าออกมา ทำอย่างไร+

เปิดโปรแกรม เลือก “รวม PDF” หรือ “แยก PDF” จากหน้าแรก แล้วเลือกไฟล์ ผลลัพธ์บันทึกเป็นไฟล์ใหม่ ไฟล์เดิมไม่เปลี่ยน

แก้ข้อความในไฟล์ PDF ได้แค่ไหน+

แก้ข้อความไทยและอังกฤษ เลือกฟอนต์และขนาดได้ เหมาะกับการแก้คำหรือบรรทัดสั้นๆ ไม่เหมาะกับการจัดหน้าใหม่ทั้งหน้า

แปลงเป็น Word แล้วได้แต่รูป ไม่ได้ข้อความ+

มักเป็นไฟล์สแกน ซึ่งในไฟล์มีแต่ภาพ ให้ทำ OCR ก่อน แล้วค่อยแปลงเป็น Word หรือ Excel การแปลงได้ผลดีที่สุดกับเอกสารที่มีข้อความจริง

ลายเซ็นที่บันทึกไว้เก็บที่ไหน ปลอดภัยไหม+

ถ้าเลือกเก็บไว้ใช้ครั้งหน้า ลายเซ็นจะถูกเข้ารหัสและเก็บในเครื่องนี้เท่านั้น

ลายเซ็นธรรมดา กับลายเซ็น Digital ID ต่างกันอย่างไร+

ลายเซ็นธรรมดาคือภาพลายมือชื่อวางบนเอกสาร ส่วน Digital ID ยืนยันตัวผู้เซ็น และตรวจพบได้ถ้ามีคนแก้เอกสารหลังเซ็น

ใบกำกับภาษี e-Tax จากโปรแกรมนี้ ใช้ส่งจริงได้เลยไหม+

โปรแกรมสร้างไฟล์ PDF/A-3 ที่มี XML ตามแบบของกรมสรรพากร และ XML ตัวอย่างผ่านการตรวจโครงสร้างบนเว็บ etax.rd.go.th แล้ว แต่ก่อนใช้จริงต้องสมัครใช้ระบบ e-Tax กับกรมสรรพากรก่อน และ XML ในรุ่นนี้ยังไม่ได้เซ็นแบบ XAdES แยกต่างหาก ควรตรวจ XML ของคุณเองและทดสอบก่อนส่งจริง ขั้นตอนอยู่ในคู่มือ

สถานะของ e-Tax ใน YRK PDF

  • ทำตามมาตรฐาน ETDA ขมธอ. 3-2560 เวอร์ชัน 2.0
  • ไฟล์ XML ตัวอย่างผ่านการตรวจโครงสร้างที่หน้าตรวจสอบของกรมสรรพากร
  • ยังไม่เคยทดสอบส่งจริงในระบบ e-Tax Invoice
  • ไม่ได้รับการรับรองจากกรมสรรพากร
  • YRK PDF ไม่ใช่ผู้ให้บริการ e-Tax Invoice ผู้ใช้ต้องตรวจไฟล์และรับผิดชอบการส่งเอง
ปิดทับข้อมูลลับแล้ว ไฟล์เดิมจะหายไหม+

ไม่หาย ผลลัพธ์บันทึกเป็นไฟล์ใหม่ และข้อมูลที่ปิดทับจะถูกลบออกจริงในไฟล์ใหม่นั้น ไฟล์เดิมไม่เปลี่ยน

งานเขียนแบบ

เปิดไฟล์ AutoCAD ได้จริงไหม ต้องมี AutoCAD ด้วยหรือเปล่า+

เปิดไฟล์ .dwg และ .dxf ได้โดยตรง ไม่ต้องมี AutoCAD พร้อมเลเยอร์และสเกล แบบที่ใช้ฟอนต์หรือวัตถุพิเศษบางอย่างอาจแสดงต่างจาก AutoCAD เล็กน้อย

วัดอะไรบนแบบได้บ้าง+

วัดระยะ ระยะตามเส้น และพื้นที่ ตามสเกลของแบบ และนับจำนวนสิ่งของบนแบบ เช่น ดวงไฟ เต้ารับ วัดผิดก็ลากมุมแก้ หรือกด Ctrl+Z ย้อนกลับได้

ส่งแบบให้คนที่ไม่มีโปรแกรม CAD ได้ไหม+

ได้ บันทึกเป็น PDF แล้วส่งต่อได้เลย Layout แต่ละแผ่นจะกลายเป็นหน้า PDF ตามสเกลจริง

อัปเดตและแจ้งปัญหา

ปรับปรุงล่าสุด: 5 พฤศจิกายน 2569

YRK PDF เป็นโปรแกรมฟรีสำหรับ Windows ที่ทำงานในเครื่องของคุณ เราเขียนนโยบายนี้เพื่อบอกตรง ๆ ว่าโปรแกรมทำอะไรกับข้อมูลของคุณบ้าง

สรุปสั้น ๆ

  • เอกสารของคุณอยู่ในเครื่องคุณเท่านั้น โปรแกรมไม่อัปโหลดไฟล์ไปที่ไหน
  • ไม่ต้องสมัครสมาชิก ไม่ต้องล็อกอิน
  • ไม่มี AI ไม่เก็บสถิติการใช้งาน ไม่มีโฆษณา และไม่ส่งรายงานข้อผิดพลาดออกจากเครื่อง
  • YRK LAB ไม่ได้รับข้อมูลใด ๆ จากโปรแกรม เว้นแต่คุณติดต่อเราเอง

เมื่อไหร่ที่โปรแกรมใช้อินเทอร์เน็ต

โปรแกรมเชื่อมต่ออินเทอร์เน็ตเฉพาะ 5 กรณีนี้ ทุกกรณีไม่มีการส่งเนื้อหาเอกสารของคุณ

  1. ตรวจหารุ่นใหม่: โปรแกรมถามหน้าดาวน์โหลดบน GitHub ว่ามีรุ่นใหม่หรือไม่ ถ้ามีจะดาวน์โหลดไว้ แล้วติดตั้งเมื่อคุณกดรีสตาร์ทเท่านั้น ไฟล์อัปเดตทุกไฟล์ต้องผ่านการตรวจลายเซ็นของ YRK ก่อน
    • ตอนเปิดโปรแกรมครั้งแรก โปรแกรมจะถามว่าจะให้ตรวจเองอัตโนมัติหรือไม่ เปลี่ยนภายหลังได้ที่ ตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย
  2. ดาวน์โหลดภาษาสำหรับอ่านข้อความจากภาพ (OCR): ดาวน์โหลดจากโครงการ Tesseract บน GitHub ครั้งเดียวต่อภาษา หลังจากที่คุณกดยืนยัน
    • การอ่านข้อความทำในเครื่องของคุณทั้งหมด
  3. เซ็นแบบมีตราประทับเวลา (timestamp): โปรแกรมส่งค่าแฮชของลายเซ็นไปให้ผู้ให้บริการตราประทับเวลา (ค่าเริ่มต้นคือ DigiCert) โดยไม่ส่งเอกสาร
    • ใช้เฉพาะเมื่อคุณเลือกตัวเลือกนี้
  4. เซ็นแบบตรวจสอบได้ระยะยาว (LTV): โปรแกรมดาวน์โหลดรายการใบรับรองที่ถูกเพิกถอน (CRL) จากผู้ออกใบรับรองที่ระบุอยู่ในใบรับรอง
    • ใช้เฉพาะเมื่อคุณเลือกตัวเลือกนี้
  5. เปิด PDF ที่เซ็นด้วยใบรับรองจากผู้ออกที่ Windows เชื่อถือ: Windows อาจถามผู้ออกใบรับรองว่าใบรับรองนั้นถูกเพิกถอนแล้วหรือยัง โดยไม่ส่งเอกสาร

ในทุกกรณีข้างต้น ผู้ให้บริการปลายทาง (GitHub, ผู้ให้บริการตราประทับเวลา, ผู้ออกใบรับรอง) จะเห็นหมายเลข IP ของคุณตามปกติของการเชื่อมต่ออินเทอร์เน็ต แต่ละรายมีนโยบายความเป็นส่วนตัวของตัวเอง

ลิงก์ในเมนูช่วยเหลือ (คู่มือ, คำถามที่พบบ่อย, ส่งความเห็น) จะเปิดในเบราว์เซอร์ของคุณ ไม่ได้เปิดในโปรแกรม ส่วนนโยบายความเป็นส่วนตัวนี้และหน้าต่างสนับสนุนผู้พัฒนาเปิดในโปรแกรม โดยไม่ใช้อินเทอร์เน็ต ปุ่ม GitHub Sponsors และ Ko-fi ในหน้าต่างสนับสนุนจะเปิดเบราว์เซอร์ก็ต่อเมื่อคุณกดเท่านั้น

  • ปุ่มส่งความเห็นทางอีเมล จะเติมเลขรุ่นของโปรแกรม รุ่น Windows และภาษาไว้ในอีเมลให้ คุณแก้หรือลบได้ก่อนกดส่ง

ข้อมูลที่เก็บไว้ในเครื่องของคุณ

โปรแกรมเก็บข้อมูลไว้ที่ %LOCALAPPDATA%\YRK\EasyPdf ไม่มีข้อมูลส่วนไหนถูกส่งออกจากเครื่อง

ข้อมูลสิ่งที่เก็บการป้องกัน
การตั้งค่าภาษา, การตรวจหารุ่นใหม่, หน่วยวัดไม่เข้ารหัส
ไฟล์ล่าสุดชื่อและที่อยู่ของไฟล์ที่เปิดล่าสุด ไม่เกิน 12 ไฟล์ ไม่เก็บเนื้อหาไม่เข้ารหัส · ล้างได้ด้วยปุ่ม "ล้างรายการไฟล์ล่าสุด"
ตรายางข้อความและรูปแบบตรายางที่คุณสร้างไม่เข้ารหัส
ข้อมูลผู้ขายสำหรับ e-Taxชื่อ เลขประจำตัวผู้เสียภาษี สาขา ที่อยู่ โทรศัพท์ อีเมล และเลขที่เอกสารล่าสุดไม่เข้ารหัส
ตั้งค่าการเซ็นดิจิทัลDigital ID ที่ใช้ล่าสุด เหตุผล สถานที่ และเซิร์ฟเวอร์ตราประทับเวลาไม่เข้ารหัส ไม่เก็บรหัสผ่าน
รูปลายเซ็นที่บันทึกไว้รูปลายมือชื่อเข้ารหัสด้วยระบบของ Windows ผูกกับบัญชีผู้ใช้ของคุณ
Digital IDใบรับรองและกุญแจสำหรับเซ็นดิจิทัลป้องกันด้วยรหัสผ่านของ Digital ID
สำเนากู้คืนสำเนาเอกสารที่ยังไม่ได้บันทึก เขียนทุก 1 นาทีเมื่อมีการแก้ไฟล์ที่มีรหัสผ่านจะยังมีรหัสผ่านเดิม · ลบเมื่อบันทึก ยกเลิก หรือปิดโปรแกรมตามปกติ
ข้อมูลภาษา OCRไฟล์ภาษาที่ดาวน์โหลดมาตรวจความถูกต้องของไฟล์ก่อนใช้
บันทึกข้อผิดพลาด (log)รายละเอียดข้อผิดพลาดของโปรแกรม อาจมีชื่อไฟล์หรือโฟลเดอร์ไม่ส่งออกจากเครื่อง · ไม่เกิน 1 MB ต่อวัน · ลบเองหลัง 14 วัน

ไฟล์ชั่วคราว: ระหว่างทำงาน โปรแกรมอาจเก็บสำเนาชั่วคราวไว้ในโฟลเดอร์ Temp ของ Windows เช่น สำหรับย้อนกลับ (undo) หรือแปลงไฟล์ DWG

  • ไฟล์ที่มีรหัสผ่านจะไม่ถูกเขียนลงไฟล์ชั่วคราวแบบไม่เข้ารหัส
  • สำเนาชั่วคราวจะถูกลบเมื่อปิดโปรแกรม หรือเมื่อเปิดโปรแกรมครั้งถัดไปถ้าครั้งก่อนปิดไม่ปกติ

การลบข้อมูล: เปิดโฟลเดอร์ข้อมูลได้จาก ตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → "เปิดโฟลเดอร์ข้อมูล" แล้วลบไฟล์ที่ไม่ต้องการ

  • การถอนการติดตั้งโปรแกรมจะไม่ลบโฟลเดอร์นี้ ถ้าต้องการลบทั้งหมดให้ลบโฟลเดอร์ %LOCALAPPDATA%\YRK\EasyPdf เอง
