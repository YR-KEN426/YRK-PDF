จุดเด่น

สิ่งที่ทำให้ YRK PDF ต่าง

ไม่ต้องมี AutoCAD

เปิดแบบ DWG / DXF ได้โดยตรง แล้ววัดได้เลย

เปิดไฟล์แบบจาก AutoCAD ได้ทันที ข้อความภาษาไทยในแบบแสดงถูกต้อง เปิดหรือปิดเลเยอร์ได้ และ Layout แต่ละแผ่นกลายเป็นหน้า PDF ตามสเกลจริง

  • วัดระยะ ระยะตามเส้น และพื้นที่ ตามสเกลของแบบ
  • นับจำนวนสิ่งของบนแบบ เช่น ดวงไฟ เต้ารับ
  • บันทึกเป็น PDF ส่งต่อให้คนที่ไม่มีโปรแกรม CAD ได้
ไม่ต้องพิมพ์ ไม่ต้องสแกน

เซ็นชื่อบนเอกสารได้ในไม่กี่วินาที

วาดลายเซ็นด้วยเมาส์หรือปากกา พิมพ์ชื่อ หรือนำเข้ารูปลายเซ็นบนกระดาษ แล้วคลิกวางตรงจุดที่ต้องการ ย่อขยายและย้ายได้

  • เลือกเก็บลายเซ็นไว้ใช้ครั้งหน้า แบบเข้ารหัสในเครื่องนี้
  • เซ็นด้วย Digital ID เพื่อยืนยันตัวผู้เซ็นและตรวจพบการแก้ไขภายหลังได้
ทำมาเพื่อคนไทย

ตราประทับ “สำเนาถูกต้อง” ในคลิกเดียว

รับรองสำเนาบัตรประชาชนหรือเอกสารได้โดยไม่ต้องพิมพ์ออกมาเซ็น ระบุว่าใช้สำหรับอะไรและใส่วันที่ ช่วยลดความเสี่ยงที่สำเนาจะถูกนำไปใช้ที่อื่น

เมนูและข้อความทั้งหมดเป็นภาษาไทย และแก้ข้อความภาษาไทยในไฟล์ PDF ได้

ความสามารถ

ครบสำหรับงานเอกสารประจำวัน

ทุกอย่างด้านล่างอยู่ในโปรแกรมเดียว ไม่มีรุ่นเสียเงิน ไม่ต้องสมัครสมาชิก

อ่านและค้นหา

เปิดหลายไฟล์เป็นแท็บ ค้นหาข้อความ ดูบุ๊กมาร์ก และ OCR ไฟล์สแกนให้ค้นหาได้

กรอกและสร้างฟอร์ม

กรอกฟอร์ม PDF และสร้างฟอร์มเอง: ช่องข้อความ ช่องติ๊ก รายการเลือก ช่องลายเซ็น

แก้ข้อความในไฟล์

แก้ข้อความไทยและอังกฤษ เลือกฟอนต์และขนาดได้ เหมาะกับการแก้คำหรือบรรทัดสั้นๆ ไม่ใช่การจัดหน้าใหม่

จัดการหน้า

หมุน ลบ ย้าย แทรกหน้า แยกและรวมไฟล์ ทำผิดก็กดเลิกทำได้

คอมเมนต์และไฮไลต์

เน้นข้อความ ใส่โน้ต วาดรูปทรง แล้วส่งไฟล์ให้ผู้อื่นอ่านความเห็นต่อได้

แปลงเป็น Word, Excel และ PowerPoint

ตารางเป็นตารางจริง รูปภาพและกราฟอยู่ตำแหน่งเดิม ตัวเลขใน Excel คำนวณได้ ได้ผลดีกับเอกสารที่มีข้อความจริง ไฟล์สแกนต้อง OCR ก่อน

รหัสผ่านและปิดทับข้อมูลลับ

ใส่รหัสผ่าน และลบข้อมูลลับออกจริง ผลลัพธ์บันทึกเป็นไฟล์ใหม่ ไฟล์เดิมไม่เปลี่ยน

PDF/A และบีบอัดไฟล์

บันทึกเป็น PDF/A สำหรับเก็บเอกสารระยะยาว และทำไฟล์ให้เล็กลงก่อนส่ง

เปรียบเทียบและทำหลายไฟล์

เทียบเอกสารสองฉบับว่าอะไรเปลี่ยน ใส่ลายน้ำ เลขหน้า และทำหลายไฟล์พร้อมกัน

ความปลอดภัย

เอกสารของคุณอยู่ในเครื่องของคุณ

ตัวโปรแกรม

  • เปิดและแก้เอกสารในเครื่อง ไม่อัปโหลดเอกสารไปที่ไหน
  • ไม่ใช้บริการ AI ไม่มีโฆษณา ไม่เก็บสถิติการใช้งาน
  • ใช้อินเทอร์เน็ตแค่ 3 กรณี: ตรวจอัปเดต (ถามก่อนตอนเปิดครั้งแรก) ดาวน์โหลดภาษาสำหรับ OCR เมื่อใช้ครั้งแรก และประทับเวลาลายเซ็นดิจิทัลถ้าคุณเลือก
  • อัปเดตทุกครั้งมีลายเซ็นของ YRK โปรแกรมติดตั้งเฉพาะอัปเดตที่ลายเซ็นตรงกับกุญแจที่ฝังไว้ในโปรแกรม (คนละเรื่องกับใบรับรองผู้เผยแพร่ของ Windows)

หน้าเว็บนี้

  • ไม่มีตัวติดตาม คุกกี้ หรือสคริปต์จากเว็บอื่น
  • เว็บและไฟล์ดาวน์โหลดอยู่บน GitHub ซึ่งมีนโยบายความเป็นส่วนตัวของตัวเอง

เริ่มใช้งาน

ติดตั้งใน 3 ขั้นตอน

  1. กด ดาวน์โหลดตัวติดตั้ง
  2. เปิดไฟล์ YRK.EasyPdf-win-Setup.exe ที่ดาวน์โหลดมา โดยปกติไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ
  3. รอสักครู่ โปรแกรมจะเปิดเอง และมีไอคอนบนเดสก์ท็อปกับเมนูเริ่ม

ไม่อยากติดตั้ง: ดาวน์โหลด แบบพกพา (zip) แตกไฟล์แล้วเปิด YRK PDF.exe ได้เลย

ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC”

ตัวติดตั้งยังไม่มีใบรับรองผู้เผยแพร่ (code signing) Windows จึงยืนยันไม่ได้ว่าใครเป็นผู้สร้าง และแสดงผู้เผยแพร่เป็น “Unknown publisher”

ก่อนกด More info แล้ว Run anyway ให้ตรวจว่าดาวน์โหลดจากหน้านี้ หรือจาก github.com/YR-KEN426 เท่านั้น และชื่อไฟล์คือ YRK.EasyPdf-win-Setup.exe ถ้าได้ไฟล์มาจากที่อื่น อย่าเปิด

การเตือนนี้ไม่ได้แปลว่าพบไวรัส อ่านว่าทำไมถึงขึ้น และ วิธีตรวจไฟล์ด้วยตัวเอง

คำถามที่พบบ่อย

มีคำถาม?

ฟรีจริงไหม มีค่าใช้จ่ายแอบแฝงหรือเปล่า

ฟรีจริงทุกความสามารถ ไม่มีรุ่นเสียเงิน ไม่มีรุ่นทดลองที่หมดอายุ ไม่มีโฆษณา และไม่ต้องใส่บัตรเครดิตหรือสมัครบัญชี

ใช้ในบริษัทหรือในงานได้ไหม

ได้ ใช้ได้ฟรีทั้งส่วนตัว ในงาน และในบริษัท ติดตั้งได้ไม่จำกัดจำนวนเครื่อง

ปลอดภัยไหม เอกสารของฉันถูกส่งไปที่ไหนหรือเปล่า

เอกสารเปิดและแก้ในเครื่องของคุณเท่านั้น โปรแกรมไม่ส่งเอกสารให้บริการ AI หรือคลาวด์ใด ๆ (OCR ทำในเครื่องด้วย Tesseract) ไม่เก็บสถิติ และไม่อัปโหลดเอกสาร รายละเอียดอยู่ในหน้า “ความเป็นส่วนตัวและความปลอดภัย” ในโปรแกรม คำว่า “ไม่มี AI” หมายถึงการทำงานของโปรแกรมกับเอกสารของคุณ ส่วนการเขียนโค้ดของโปรแกรม ผู้พัฒนาใช้เครื่องมือ AI ช่วย และเป็นผู้ทดสอบและดูแลเอง

ทำไมตอนติดตั้งขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC”

หน้าจอนี้มาจาก Microsoft Defender SmartScreen ซึ่งมักเตือนโปรแกรมที่ยังไม่มี “ใบรับรองผู้เผยแพร่” (code signing certificate) หรือยังมีคนดาวน์โหลดไม่มาก ใบรับรองนี้เป็นบริการที่ต้องซื้อรายปี โปรแกรมฟรีจากผู้พัฒนารายเล็กจึงมักยังไม่มี Windows จึงแสดงผู้เผยแพร่เป็น “Unknown publisher”

การเตือนนี้ ไม่ได้แปลว่าพบไวรัส แต่แปลว่า Windows ยังยืนยันไม่ได้ว่าใครเป็นผู้สร้าง ถ้า Microsoft Defender พบไวรัสจริง จะแจ้งว่าพบภัยคุกคาม (threat) และกักไฟล์ไว้ ไม่ใช่หน้าจอนี้

การตัดสินใจติดตั้งเป็นของคุณ ถ้าดาวน์โหลดจากหน้านี้หรือจาก github.com/YR-KEN426 และตรวจไฟล์ตามหัวข้อถัดไปแล้ว ติดตั้งต่อได้โดยกด More info (ข้อมูลเพิ่มเติม) แล้ว Run anyway (เรียกใช้ต่อไป) ถ้าได้ไฟล์มาจากที่อื่น เช่น ส่งต่อกันในแชต อย่าเปิด ให้ดาวน์โหลดใหม่จากหน้านี้

ตรวจสอบไฟล์ก่อนติดตั้งอย่างไร

ทำได้ 2 วิธี และทำทั้งสองอย่างได้:

1. สแกนด้วย Windows Security: คลิกขวาที่ไฟล์ YRK.EasyPdf-win-Setup.exe แล้วเลือก “Scan with Microsoft Defender” (ใน Windows 11 อยู่ใน “Show more options”)

2. เทียบลายนิ้วมือไฟล์ (SHA-256): ตรวจว่าไฟล์ที่ได้ตรงกับที่เราเผยแพร่ทุกไบต์ เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด แล้วพิมพ์ Get-FileHash .\YRK.EasyPdf-win-Setup.exe แล้วเทียบตัวเลขกับค่า sha256 ของไฟล์นั้นในหน้า รายละเอียดรุ่นล่าสุด (ตัวพิมพ์เล็กหรือใหญ่ไม่มีผล) ถ้าตรงกัน แปลว่าไฟล์ของคุณคือไฟล์เดียวกับที่เราเผยแพร่ ไม่ถูกแก้ไขหรือสลับระหว่างทาง

หมายเหตุ: การเทียบ SHA-256 ยืนยันว่าไฟล์ตรงกับรุ่นที่เผยแพร่เท่านั้น ไม่ได้ตรวจหาไวรัส การตรวจไวรัสใช้วิธีที่ 1

ทำไมติดตั้งได้โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

โปรแกรมติดตั้งเฉพาะในบัญชีผู้ใช้ของคุณ (โฟลเดอร์ AppData) ไม่แตะไฟล์ระบบของ Windows จึงไม่ต้องขอสิทธิ์ผู้ดูแลระบบ ยกเว้นกรณีเดียว: ถ้าเครื่องยังไม่มี Microsoft Visual C++ Runtime ที่ใช้สำหรับ OCR ตัวติดตั้งจะขอสิทธิ์เพื่อติดตั้งส่วนนี้ของ Microsoft

อัปเดตอัตโนมัติปลอดภัยไหม ถ้ามีคนปลอมอัปเดตล่ะ

อัปเดตทุกครั้งเซ็นด้วยกุญแจส่วนตัวของ YRK ซึ่งอยู่ในเครื่องของผู้พัฒนาเท่านั้น โปรแกรมของคุณมีกุญแจสาธารณะฝังอยู่ และจะติดตั้งเฉพาะอัปเดตที่ลายเซ็นตรงกันเท่านั้น ถ้ามีคนแก้ไฟล์อัปเดตบนเว็บ ลายเซ็นจะไม่ตรง และโปรแกรมจะไม่ติดตั้ง นอกจากนี้โปรแกรมถามก่อนตอนเปิดครั้งแรกว่าจะให้ตรวจหาอัปเดตหรือไม่ และไม่ติดตั้งอะไรจนกว่าคุณจะกด “รีสตาร์ทเพื่ออัปเดต”

โปรแกรมแอนตี้ไวรัสของฉันเตือน ทำอย่างไรดี

คำเตือนอาจเกิดได้จากหลายสาเหตุ เช่น โปรแกรมยังใหม่และยังไม่มีใบรับรองผู้เผยแพร่ หรือไฟล์ถูกเปลี่ยนระหว่างทาง ให้หยุดติดตั้งก่อน แล้วตรวจว่าดาวน์โหลดจากหน้านี้ และค่า SHA-256 ตรงกับหน้ารายละเอียดรุ่น

จากนั้น แจ้งเรา พร้อมชื่อโปรแกรมแอนตี้ไวรัส ชื่อภัยคุกคามที่แสดง และรุ่นของไฟล์ เราจะตรวจสอบและตอบกลับ

ต้องต่ออินเทอร์เน็ตไหม

ไม่ต้อง ทุกความสามารถใช้แบบออฟไลน์ได้ ยกเว้น OCR ภาษาที่ยังไม่มีในเครื่อง ซึ่งต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อดาวน์โหลดไฟล์ภาษา นอกจากนั้นอินเทอร์เน็ตใช้เฉพาะตอนตรวจอัปเดต (ถ้าอนุญาต) และประทับเวลาลายเซ็นดิจิทัล (ถ้าเลือก)

ใช้กับ Mac หรือมือถือได้ไหม

ตอนนี้รองรับเฉพาะคอมพิวเตอร์ Windows 10 และ 11 แบบ 64 บิต

เปิดไฟล์ AutoCAD ได้จริงไหม ต้องมี AutoCAD ด้วยหรือเปล่า
